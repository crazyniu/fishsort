# UX 规格：海图（2026-11-17）

状态：**已实现（`pages/map.ts`），先做后补的规格，待用户在模拟器里验收**。玩法见 `docs/01` 5.7。

## 玩家目标

看清一共有哪些海域、现在在哪、每片过了多少；点一片开了的海域去选关。

## 布局（750×1334）

```
[←]            「海图」                  页头（和别的子页面同一个），背景是主页的海底图
┌──────────────────────────────┐         一片海域一张卡 680×230（蓝色块），从上往下第 1–12 片，可以上下滑
│[海域名]               [当前] │         画面：这片海域的局内背景，取中间偏下一截；左上海域名牌；现在所在的海域右上一面「当前」
│        （海域的画面）         │
│ 第 1–20 关          [■■■□ 15/20]│        下面一条半透明深色底：关卡范围 + 进度条（过了几关）
└──────────────────────────────┘
  ……
┌──────────────────────────────┐         没到的海域：画面变灰，写「🔒 第 N 关解锁」，点了晃一下、提示先过前面的关
```

- 打开时停在现在所在的海域（上面露出一点前一片）。
- 主页「选关」键先到这里；选关页的返回回到这里。

## 交互

- 点开了的海域 → 选关页停在这片海域那一页（`ui.go('levels', { sea })`）。
- 点没开的海域 → 卡晃一下 + 错误音 + 「先通过前面的关卡」。

## 文案

| 键 | 中文 | English |
|---|---|---|
| MAP_TITLE | 海图 | Sea Map |
| MAP_RANGE | 第 %d–%d 关 | Levels %d–%d |
