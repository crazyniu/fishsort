# UX 规格：海图（2026-11-17）

状态：**已实现（`pages/map.ts`），先做后补的规格，待用户在模拟器里验收**。玩法见 `docs/01` 5.7。

## 玩家目标

看清一共有哪些海域、现在在哪、每片过了多少；点一片开了的海域去选关。

## 布局（750×1334）

```
[←]            「海图」                  页头（和别的子页面同一个），背景是主页的海底图
┌────────────┐  ┌────────────┐          一片海域一张竖版卡 330×470（蓝色块），两列、六行，从左到右、从上往下第 1–12 片，可以上下滑
│ [海域名]   │  │ [海域名]   │          （用户 2026-11-17：原来的横条只截到一截海底，看着空，改竖版）
│            │  │            │          画面：这片海域的整张局内背景（竖图，差不多整张放得下）；上面海域名牌
│  （画面）  │  │    🔒      │          没到的海域：画面灰一点、中间一把大锁
│   [当前]   │  │            │          现在所在的海域：画面下方贴一面「当前」，整张卡轻轻呼吸
│第 1–20 关  │  │第 21–40 关 │          下面一条半透明深色底：第一行关卡范围
│[■■■□15/20] │  │🔒第 21 关解锁│          第二行进度条（过了几关），没到的写「🔒 第 N 关解锁」
└────────────┘  └────────────┘
```

- 打开时停在现在所在的海域那一行（上面露出一点前一行）。
- 主页「选关」键先到这里；选关页的返回回到这里。

## 交互

- 点开了的海域 → 选关页停在这片海域那一页（`ui.go('levels', { sea })`）。
- 点没开的海域 → 卡晃一下 + 错误音 + 「先通过前面的关卡」。

## 文案

| 键 | 中文 | English |
|---|---|---|
| MAP_TITLE | 海图 | Sea Map |
| MAP_RANGE | 第 %d–%d 关 | Levels %d–%d |
