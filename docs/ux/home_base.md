# UX 规格：家园「重建海湾」

状态：**用户已授权按经验定细节**（issue #45），外壳与逻辑一并做出，截图验收。规则与数值见 `docs/01` 第 5.12 节。

## 玩家目标

把星星和金币花出去，看着海湾一步步亮起来。主行动只有一个：**建造下一步**。

## 主次层级

- 主行动：底部绿色「建造」按钮（560×116），按钮上直接写这一步花几颗星、多少金币，不够的数字变红。
- 次信息：顶部星星数（左）、金币数（右）、区域序号「区域 1/5」（中）；场景下方一行「第 2/5 步：铺贝壳小路」和 5 格进度 + 区域宝箱。
- 没有次行动按钮。家园是底栏页签，不显示主页顶栏（金币、生命、设置），所以本页自带星星和金币胶囊。

## 元素

| 元素 | 说明 |
|---|---|
| 场景底图 | `assets/base/<区域>_bg.jpg`；没有图时用 `assets/ui/home_scene.jpg` |
| 物件 | `assets/base/<区域>_<步>.png`；没有图时用 `basePage.steps` 里配的占位图（现有生物 / 道具图标）。已建：原色 + 金光垫底；未建：深蓝剪影；下一步：呼吸光圈 |
| 进度格 | 5 格星星（已建亮）+ 最后一格区域宝箱（建完变开箱） |
| 建造按钮 | 「建造」+ 星星花费 + 金币花费 |

## 状态

| 状态 | 表现 |
|---|---|
| 未解锁（第 30 关前） | 锁页：大图标、「第 30 关解锁」、大奖面板（6 个区域宝箱、合计 25500 金币、技能 ×40、10 小时无限生命） |
| 默认（可建） | 按钮呼吸，底栏家园页签亮红点 |
| 星星不够 | 星星数字红色；点按钮提示「星星不够：首次过关得星星」 |
| 金币不够 | 金币数字红色；点按钮弹「金币不足」（可看广告领金币） |
| 下一区域没到开放关 | 场景压暗 + 锁 +「第 N 关解锁」；按钮变灰显示同样文字；进度格全暗 |
| 全部建完 | 停在最后一个区域，全部物件亮；按钮灰色「海湾已全部重建」 |
| 加载中 / 出错 / 空 | 无（纯本地数据） |

## 动效

- 进场：场景弹出（0.25 秒）。
- 常驻：下一步位置的光圈呼吸；主按钮呼吸（够钱够星时）。不超过 2 处。
- 点击建造：物件从小弹大 + 金光一闪 + 星星飞溅，星星、金币数字滚动减少，对应进度格弹一下（约 0.45 秒）。
- 建完区域：0.7 秒后压暗，宝箱弹出、左右越晃越大，弹开冒金币、星星、彩纸，然后弹开奖弹窗；收下后整页换成下一个区域。

## 参考结论

- 同类「消除 + 装修」休闲游戏的共同做法：过关得一种专用货币（星星），在一张场景上逐项修复；每项一点即建，带一段短动画；整片场景完成给大奖，然后进入下一片场景。
- 取：一页一个场景、一个主按钮、完成大奖、按关分段开放。
- 不取：任何一款的场景画面、物件造型、布局坐标；不做自由摆放、不做多选一的装修款式（v1.0 范围外）。

## 验收点

1. 第 31 关进家园页，3 秒内看出「建造」是主行动、花费是多少。
2. 点建造：物件亮起有动画，星星和金币数字减少，进度格亮一格。
3. 建完一个区域：宝箱动画 + 开奖弹窗，收下后进入下一区域（未到开放关时显示锁和开放关）。
4. 星星或金币不够时有明确提示，不扣任何东西。
5. 没有正式出图时，所有物件都有占位图，不出现空白。
