# UX 规格：加载页（2026-11-18）

状态：**已实现**（2026-11-18，用户「你来改吧」：下面三个待确认项按建议做——背景用主页那张、放健康游戏忠告、要小贴士）。代码在 `ui/loading.ts`，步骤和重试在 `Boot.ts`。

## 玩家目标

从点开游戏到主页出来的这几秒，知道游戏在加载、大概还要多久；第一眼就记住游戏的样子（logo、名字）。网不好、下不下来时知道该怎么办。

## 启动的三段

| 段 | 谁画的 | 画面 |
|---|---|---|
| 1. 平台的启动屏 | 平台自己 | 微信：游戏图标 + 名字 + 它自己的进度（下载主包）。iOS：启动屏（LaunchScreen），Android：启动图——这两个是静态图，在原生工程里配，用下面加载页同一张背景 + logo，切过来时画面不跳 |
| 2. 引擎的启动 logo | Cocos | 不出现。引擎的启动画面时长是 0，引擎直接跳过；微信版另有一个「首屏」（引擎脚本加载时 Cocos 模板画 logo、标语和进度条），用 `client/build-templates/wechatgame/first-screen.js` 换掉了，只铺加载页同色的海蓝（用户 2026-11-18：启动时先闪一下 Cocos 的界面，去掉） |
| 3. **我们的加载页** | 游戏 | 本规格。读资源包、存档和配置、文案、字体、界面图、眼前这片海域的鱼。微信版的资源包放在网上（`docs/04` 第 8 节），第一次打开要下载约 9 MB，以后读手机里的缓存 |

## 进度怎么算

- 加载分几步，各占一段：资源包目录 4% → 平台、存档和配置 4% → 文案 2% → 字体 15% → 界面图和眼前海域的鱼 75%（按已读的文件数推进）。条不倒退。音效不算在里面，主页出来后在后台读。
- 加载页出来时资源包还没读，所以它只用本地 `boot` 包（`client/assets/boot/`：背景 `bg.jpg`、图标 `logo.png`、文案 `strings.json`），字用系统字体，按钮自己画。语言在读到存档后才定（之前按中文）。
- 加载太快（不到 0.8 秒）也让条走完再进主页，不闪一下就没了。
- 到 100% 后停 0.2 秒，整页淡出、主页淡入。

## 出错

- 下载失败（微信分包、远程资源）：进度条换成一行「网络不太好，加载失败」+ 绿色「重试」键，点了从失败的那一步接着下。
- 本地资源出错（不该发生）：调试构建照现在这样把错误画在屏幕顶上。
