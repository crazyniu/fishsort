# UX 规格：局内界面（补写，以现有实现为准）

状态：**已实现（Cocos 版 `game/gameView.ts`、`game/field.ts`），补写规格，用户 2026-11-16 确认**。规则见 `docs/01` 第 1–4 节；版面以定版图 `art/ui-final/12_局内.png`（只在本地）为起点，连击、鱼缸、气泡重力按用户 2026-11-16 的试玩反馈改过。本文重点写清 2026-11-16 关卡设计复查后新增的表现：迷雾、冰封、提示和引导。

## 玩家目标

找到鱼缸要的那种鱼，点它。

## 主次层级

- 主行动：点气泡里的鱼。气泡场占屏幕 60%，是全屏最大、最亮的区域。
- 次行动（不超过 3 类）：点技能键（底部 4 个）；点没开的缸位「＋」；点设置。
- 信息：已救数、关卡号、每个缸要什么和进度、暂存槽、连击。

- 气泡受重力：没有遮挡的关卡开局一个接一个落下来堆满场地，破一个上面的就压下来。场地有顶，堆高了最上面的气泡会被压回场地里，不会停在场地外面点不到（用户 2026-11-18 试第 140 关）。
- 排队泡（第 28 关起，`docs/01` 第 4 节）：泡里的鱼从左下到右上斜着排成一队、朝同一个方向，排头最亮，后面的压暗成灰蓝色；点泡上任何一条都算点排头。

| 气泡 | 被压住（分层关） | 压暗、染深蓝、缩小到 93%；点它会晃一下 |
| 锁链泡 | 锁着 | 两条链交叉锁住，右下角红色数字 = 还差几缸；点它会晃 |
| 锁链泡 | 解开 | 链子放大淡出，冒几颗星 |
| 迷雾泡 | 没显形 | 气泡里蒙一团云雾；每条鱼的位置各放一个**一模一样的问号球**（淡紫蓝的果冻球，上面一个白色「?」，问号画在图里；看得出几条，看不出是什么）；气泡下沿一排小泡泡 = 还要破几个别的气泡才显形，别处每破一个气泡，这里就破一个（用户 2026-11-16：原来的数字角标看不懂）。雾也跟着淡一层 |

| 迷雾泡 | 显形 | 雾放大散开，问号球一个个翻面变成真的鱼（每条错开 0.05 秒），冒几颗星 |
| 冰封泡 | 冻着 | 气泡外面罩一块冰（厚冰按裂了几道换图）。**颜色配对**（2026-11-20 改，用户：冰晶连线看不懂、连得也不准——线从中心拉到中心，穿过别的气泡、停在半空）：每块冰一个组色（蓝、紫、橙、绿、粉轮着用）；冰封泡下沿一块组色圆牌，左上角一朵小雪花，中间写还要点破几个；它依赖的那几个气泡右上角各挂一块同色雪花牌（画在最上面一层，被压住的也看得见；一个气泡被好几块冰依赖就并排挂几块）。依赖的气泡破一个，冰面裂一道、计数牌的数字减一、跳一下；全部破完冰化掉、雪花牌一起收掉。点冰封泡：它依赖的雪花牌跳一下、那几个气泡外一圈同色光，提示「先点破带同色雪花的气泡」。原来的冰晶连线删掉 |
| 冰封泡 | 解冻 | 依赖的气泡任一个破掉：冰块淡出、连线收起、冒几颗冰蓝的星 |
| 结伴鱼 | — | 两条鱼之间一条粉色的绳；点一条两条一起飞 |
| 鱼缸 | 要鱼 | 空缸里什么都没有（用户 2026-11-16：缸里画着目标鱼会以为已经有一条）。木架下面钉着这个缸的目标卡：一叠白边相片（Codex 画的），上面是要的那种鱼，画得大；右下角白字深蓝描边的「0/3」（进了几条 / 要几条） |

| 鱼缸 | 限时 | 缸的右上角多一个红色圆牌，写着剩余秒数，每秒更新 |

## 提示与引导

- **提示光圈**：玩家一段时间没动（前 3 关 2 秒，其它关 7 秒），给机器人会点的那条鱼套一个金色脉动光圈，前 3 关再加一只手指。**光圈不指向没显形的迷雾鱼**：这时要是没有别的鱼可点，就不给提示。
- **新机制说明**：解锁关开局弹一句说明（「知道了」关闭），每个机制只弹一次。说明上面是用局内同一套图摆的小场景（分层是一前一后两个泡、锁链泡带锁链和数字、迷雾泡带问号和下沿小泡、冰封泡带组色计数牌、旁边的气泡带同色雪花牌、限时缸和大鱼缸带目标卡），让人对上局里看到的东西（用户 2026-11-17：只有一行字时弹窗中间空一大块）。哪一关弹跟着难度曲线走：分层 3、锁链 16、掉落 26、排队泡 28、限时缸 31、迷雾 41、冰封 61、大鱼缸 81、结伴鱼 111。掉落（26）和限时缸（31）不在同一关。
- 每日挑战里不弹说明、不给新技能教学。

## 动效

- 进场：鱼缸从上面落到木架上；气泡一个接一个落下。
- 背景：每个海域一张有景物的画，景物在两边和底部、颜色压低，中间留给气泡（`docs/03` 第 3 节）。
- 限时关（`docs/01` 第 4 节，只有第 61 关起的挑战关）：连击起算后每命中一次加 1–2 秒，倒计时条弹一下、下面飘一个绿色的「+N」（不带单位，挨着倒计时看得懂）。顶栏正中一块和两边一样的深蓝倒计时条，只写时间（3:20），不放时钟图标（用户 2026-11-17），走第一步才开始走，剩 15 秒变成黄色字、一跳一跳并响一声；用完算输，复活再给 30 秒。
- 提醒用道具（`docs/01` 5.2）：暂存槽只剩 2 格、或场上没有能进缸的鱼时，能救场的技能键发光跳动，最对症的那个上面有一只点动的小手（只指本关还能用、点了有效果的技能，或者有空缸位时指开缸的「＋」）。暂存槽满了、手里有吹泡时先弹「槽位满了」（标题牌、吹泡大图标带数量角标、一句「用吹泡清空槽位，接着玩」、绿色主按钮「用吹泡」、蓝色次按钮「不用」），版式同复活弹窗。
- 限时缸装满：和普通缸不一样——红色倒计时牌变成绿色对勾、弹一下，缸上方升起金色的「赶上了！」，光和光环是金色的，多一声升档音、中等震动（用户 2026-11-17：原来和普通缸一样，看不出赶上了）。
- 稀客：这关宝箱开出卡时，那张卡做成发光的小卡钉在一个气泡边上（`docs/01` 3.4）；气泡破了它飞出来亮相、提示「救出 XX！」。
- 常驻：所有生物隔几秒眨一下眼；气泡里、鱼缸里、目标卡上的生物都一直在动，按种类做小动作（螃蟹摇着摇着夹两下、水母一缩一伸、章鱼慢慢摆、贝壳一开一合……，其余的鱼轻轻摆尾，见 `docs/03` 4.2）；泡膜果冻似地慢慢变形、彩虹流光沿边转、偶尔闪一颗星；背景和鱼缸里有小气泡往上冒；提示光圈脉动。这几样都很轻，不抢「点鱼」（用户 2026-11-16 要求加）。
- 点击反馈：点鱼「啵」一声，鱼先放大再沿弧线游进缸，缸里溅水、牌子弹一下；进暂存槽是另一种更闷的声音。
- 连击（4 连起算，7 / 10 / 15 升档）：四边光框、放射光、彩纸、全场气泡波纹、震动，逐档加强；断连时光框收掉。光框、放射光、彩纸、烟花、鱼缸上炸的光都垫在玩法后面，不盖鱼缸、目标卡和气泡（用户 2026-11-16）。
- 所有演出都不挡操作，随时可以继续点。

## 参考结论

同类「取物进容器」的消除游戏的共同做法：目标容器在上、待取物在中间最大的区域、道具在最下面；障碍都直接画在物件上，不另开图例；隐藏信息的障碍给一个看得见的「什么时候解开」的数字或进度。我们取这三条。不取：用剪影表示隐藏的物件（本作同关生物轮廓各不相同，剪影等于没藏）；用文字解释障碍（只在解锁关说一句）。

## 验收点

1. 迷雾泡没显形时，从画面上看不出里面是哪种鱼，但数得出几条；下沿的小泡泡一看就知道还要破几个。
2. 冰封泡连着哪一两个气泡，一眼看得出来；气泡被挤开后连线还连着。
3. 一个气泡上不会同时出现雾和冰、雾和锁链。
4. 提示光圈从不套在问号球上。
5. 第 26 关只弹掉落的说明，第 31 关只弹限时缸的说明。
