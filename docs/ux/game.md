# UX 规格：局内界面（补写，以现有实现为准）

状态：**已实现（Cocos 版 `game/gameView.ts`、`game/field.ts`），补写规格，用户 2026-11-16 确认**。规则见 `docs/01` 第 1–4 节；版面以定版图 `art/ui-final/12_局内.png`（只在本地）为起点，连击、鱼缸、气泡重力按用户 2026-11-16 的试玩反馈改过。本文重点写清 2026-11-16 关卡设计复查后新增的表现：迷雾、冰封、提示和引导。

## 玩家目标

找到鱼缸要的那种鱼，点它。

## 主次层级

- 主行动：点气泡里的鱼。气泡场占屏幕 60%，是全屏最大、最亮的区域。
- 次行动（不超过 3 类）：点技能键（底部 4 个）；点没开的缸位「＋」；点设置。
- 信息：已救数、关卡号、每个缸要什么和进度、暂存槽、连击。

            不错！                          夸奖字：升档时也在这一排弹出，这时连击计先淡出，不盖气泡

[洗牌][吹泡][渔网][洋流]                    技能键 4 个，每个 156×168，右上角红色圆角标是剩余数量（只写数字）

- 顶栏避开刘海；技能键在下半屏拇指区，底部留手势条的安全距离。
- 局内不显示金币和生命；金币只出现在弹窗和结算页。
- 气泡受重力：没有遮挡的关卡开局一个接一个落下来堆满场地，破一个上面的就压下来。

## 状态

| 对象 | 状态 | 表现 |
|---|---|---|
| 气泡 | 能点 | 正常亮度；点鱼时气泡被「拔」一下 |
| 气泡 | 被压住（分层关） | 压暗、染深蓝、缩小到 93%；点它会晃一下 |
| 锁链泡 | 锁着 | 两条链交叉锁住，右下角红色数字 = 还差几缸；点它会晃 |
| 锁链泡 | 解开 | 链子放大淡出，冒几颗星 |
| 迷雾泡 | 没显形 | 气泡里蒙一团云雾；每条鱼的位置各放一个**一模一样的问号球**（淡紫蓝的果冻球，上面一个白色「?」；看得出几条，看不出是什么）；气泡下沿一排小泡泡 = 还要破几个别的气泡才显形，别处每破一个气泡，这里就破一个（用户 2026-11-16：原来的数字角标看不懂）。雾也跟着淡一层 |
| 迷雾泡 | 没显形时被点 | 可以点。点中的那个问号球消失，鱼现出原形飞走；其余的仍是问号 |
| 迷雾泡 | 显形 | 雾放大散开，问号球一个个翻面变成真的鱼（每条错开 0.05 秒），冒几颗星 |
| 冰封泡 | 冻着 | 气泡外面罩一块冰；向它依赖的 1–2 个气泡各拉一条**冰晶连线**：一串小冰块（和罩在气泡上的是同一张冰块图），从冰封泡的边排到依赖泡的边，画在所有气泡上面。两头的气泡动了，连线每帧跟着走。点它会晃 |
| 冰封泡 | 解冻 | 依赖的气泡任一个破掉：冰块淡出、连线收起、冒几颗冰蓝的星 |
| 结伴鱼 | — | 两条鱼之间一条粉色的绳；点一条两条一起飞 |
| 鱼缸 | 要鱼 | 空缸里什么都没有（用户 2026-11-16：缸里画着目标鱼会以为已经有一条）。缸前面叠着订单卡，每张卡上是要的那种鱼，还差几条就有几张，略微错开成扇形，盖住缸的下半截 |
| 鱼缸 | 进鱼 | 鱼游进缸里留在水里（3 条摆成三角，6 条两排），最前面那张订单卡往上一弹、转着淡掉，剩下的往中间收 |
| 鱼缸 | 限时 | 缸的右上角多一个红色圆牌，写着剩余秒数，每秒更新 |
| 鱼缸 | 大鱼缸 | 叠 6 张订单卡，卡小一号 |
| 缸位 | 没开 | 暗缸加绿色「＋」，点了弹「开启缸位」 |
| 暂存槽 | 只剩 1 格 | 那一格红框闪 |
| 技能键 | 没解锁 | 灰锁加「第 N 关」 |
| 技能键 | 数量为 0 | 右上角的数量换成绿色「＋」，点了弹购买 |

一个气泡只带一样障碍：锁着或冻着的气泡不会再蒙雾（生成器保证）。

## 提示与引导

- **提示光圈**：玩家一段时间没动（前 3 关 2 秒，其它关 7 秒），给机器人会点的那条鱼套一个金色脉动光圈，前 3 关再加一只手指。**光圈不指向没显形的迷雾鱼**：这时要是没有别的鱼可点，就不给提示。
- **新机制说明**：解锁关开局弹一句说明（「知道了」关闭），每个机制只弹一次。哪一关弹跟着难度曲线走：分层 3、锁链 16、掉落 26、限时缸 31、迷雾 41、冰封 61、大鱼缸 81、结伴鱼 111。掉落（26）和限时缸（31）不在同一关。
- 每日挑战里不弹说明、不给新技能教学。

## 动效

- 进场：鱼缸从上面落到木架上；气泡一个接一个落下。
- 常驻：气泡里的鱼轻轻摆尾；泡膜果冻似地慢慢变形、彩虹流光沿边转、偶尔闪一颗星；背景和鱼缸里有小气泡往上冒；提示光圈脉动。这几样都很轻，不抢「点鱼」（用户 2026-11-16 要求加）。
- 点击反馈：点鱼「啵」一声，鱼先放大再沿弧线游进缸，缸里溅水、牌子弹一下；进暂存槽是另一种更闷的声音。
- 连击（4 连起算，7 / 10 / 15 升档）：四边光框、放射光、彩纸、全场气泡波纹、震动，逐档加强；断连时光框收掉。
- 所有演出都不挡操作，随时可以继续点。

## 参考结论

同类「取物进容器」的消除游戏的共同做法：目标容器在上、待取物在中间最大的区域、道具在最下面；障碍都直接画在物件上，不另开图例；隐藏信息的障碍给一个看得见的「什么时候解开」的数字或进度。我们取这三条。不取：用剪影表示隐藏的物件（本作同关生物轮廓各不相同，剪影等于没藏）；用文字解释障碍（只在解锁关说一句）。

## 验收点

1. 迷雾泡没显形时，从画面上看不出里面是哪种鱼，但数得出几条；下沿的小泡泡一看就知道还要破几个。
2. 冰封泡连着哪一两个气泡，一眼看得出来；气泡被挤开后连线还连着。
3. 一个气泡上不会同时出现雾和冰、雾和锁链。
4. 提示光圈从不套在问号球上。
5. 第 26 关只弹掉落的说明，第 31 关只弹限时缸的说明。
