# UX 规格：图鉴（补写，以现有实现为准）

状态：**已实现（`src/ui/dex_page.gd`），补写规格，待用户确认**。玩法见 `docs/01` §5.13。

## 玩家目标

看自己救过哪些生物，把救够数量的金币领走。

## 主次层级

- 主行动：有奖的格子里绿色「领取」按钮（脉动）。
- 次行动：无（格子本身不可点，没有详情页）。
- 信息：已遇见 N/16、每种生物的名字、累计数量与到下一档的进度。

## 布局（750×1334）

```
标题「图鉴」                              y 18
已遇见 N/16 种（26 号，居中）              y 88
滚动区 y 134 起，3 列，每格宽约 218 × 高 220
┌ 格子 ─────────┐
│ 气泡 116 + 鱼 76 │
│ 名字 24 号       │
│ [领取] 或 进度条 + n/need │
└───────────────┘
```

页面铺一整块深色底板；格子是 `popup_row` 底。

## 状态

| 状态 | 表现 |
|---|---|
| 没救过（0 只） | 鱼是深蓝剪影，名字写「？？？」，没有进度条 |
| 救过、没到下一档 | 鱼摆动；名字；进度条 + `n/下一档数` |
| 到档未领 | 进度条换成绿色「领取」（脉动）；底栏图鉴页签有红点 |
| 三档全领完 | 进度条是空槽，只写累计数量 |
| 功能未开放（第 10 关前） | 不进本页，显示锁页，带大奖预览（2200 金币） |

## 交互

- 点「领取」→ 金币入账 → 开奖弹窗（标题「图鉴」，单个金币大奖）→ 点「收下」刷新页面和红点。
- 滚动：上下拖动列表。

## 动效

- 进场：前 9 个格子依次弹出（间隔 0.03 秒）。
- 常驻：救过的鱼摆动；「领取」按钮脉动。
- 点击：按钮标准按下缩放。

## 参考结论

图鉴类的共同做法：未发现用剪影、发现后显示名字和计数、里程碑奖励。取「剪影 + 计数 + 档位奖励」；不取具体的卡面和分类方式。

## 验收点

1. 一眼分清哪些救过、哪些没救过。
2. 有奖的格子「领取」最显眼，领完红点消失。
3. 16 种生物都在，滚动顺畅、不卡。
4. 进度条显示的是「当前数量 / 下一档数量」。

## 待确认（实现与 `docs/01` 不一致或文档没写）

1. 格子**不可点**，没有生物详情（名字以外的信息、每档奖励金额）。玩家看不到「30 / 100 / 300 只各领 200 / 500 / 1500」。要不要加详情或在页面顶部写一行说明？docs/01 没要求。
2. 三档全领完后只显示累计数量，没有「已集满」标记。
3. 页面顶部「已遇见 N/16 种」是实现加的，docs/01 没写，建议补进文档。
4. 档位数值取自 `economy.json` 的 `dex`，页面只显示 `n/need`，没有写出每档奖励金额。
