# UX 规格：任务中心

状态：**用户 2026-11-16 让先写代码，规格同时写；外壳做完在 Mac 上截图验收**。实现在 `pages/tasks.ts`，玩法见 `docs/01` §5.9。

## 玩家目标

看今天还差哪项任务没做，点一下去做；有宝箱就开。

## 主次层级

- 主行动：可以开的宝箱（晃动、带红点）。没有可开的宝箱时，是第一条没做完任务右边的「前往」按钮（绿，130×80）。
- 次行动：其余任务的「前往」；点没到档的宝箱看里面有什么。
- 信息：今日积分、本周积分、离周一重置还有几天、每项任务的进度和积分。

## 布局（750×1334）

```
[返回]      [ 任务中心 ]                 页头（各子页面同一个）：返回键 88 在左上，标题牌居中，中线 y = 顶 − 76
┌ [今日|本周]              70/100 ┐   一块白色面板 690×250：左上两段切换，右上积分
│ ━━━━[箱]━━━━[箱]━━━━[箱]━━━━[箱]  │   黄色进度条 560×26 串着各档宝箱（96），等距，最后一只在条的末端
│      20      50      80     100   │   宝箱下面是这一档的积分；看本周时右上多一行「N 天后重置」
└───────────────────────────────────┘
┌──────────────┐ ┌──────────────┐     任务卡片：两列、三行，占满面板下面的地方（卡片最高 280）
│   [图标]  +30 │ │   [图标]  +20 │     从上到下：图标（右上角琥珀色小标签写积分）→ 任务名 →
│    过 3 关    │ │  救 30 只小鱼 │     进度条（数字写在条上）→「前往」
│  ━━ 1/3 ━━   │ │  ━━ 12/30 ━━ │
│   [ 前往 ]    │ │   [ 前往 ]    │
└──────────────┘ └──────────────┘
  ……共 6 张
```

- 用户 2026-11-16：原来今日、本周各一块面板，下面是一行行的列表，「像网页」——合成一块可切换的面板，任务改成卡片。
- 另一边（今日 / 本周）有宝箱可领时，那一段上亮红点。
- 宝箱等距排，不按积分比例排（80 和 100 按比例会挤在一起）；进度条按「到了第几档、离下一档多远」折算。
- 没做完的卡片是蓝色的块，排前面；做完的换成白色卡片，下面一个对勾，没有进度条和按钮。
- 主页入口进来的子页面：左上角返回，不显示顶栏。从这里「前往」别的页面，那一页的返回键回到这里。
- 6 张卡片一屏放得下，不用滚动；屏幕矮时卡片和图标跟着缩。

## 状态

| 状态 | 表现 |
|---|---|
| 任务没做完 | 蓝色卡片，进度条和「N/目标」，右上积分标签，下面「前往」 |
| 任务做完 | 白色卡片，下面换成对勾，排到后面 |
| 宝箱没到档 | 灰色、关着；点了弹出里面有什么（只看，不发） |
| 宝箱可开 | 彩色、隔一会晃一下、右上红点；主页的任务入口亮红点 |
| 宝箱已开 | 开着的宝箱图 |
| 未解锁（第 11 关前） | 主页入口灰色带锁，点进去是共用的锁页：「第 11 关解锁」+ 本周最后一档宝箱的内容 |
| 跨天 / 跨周 | 再进页面时任务换新、积分清零；没有单独提示 |

## 「前往」去哪

| 任务 | 去处 |
|---|---|
| 过关、救鱼、连击、用技能 | 直接开始当前这一关（没命时走原有的生命弹窗） |
| 看广告 | 商店（看广告领金币在那里） |
| 每日挑战 / 抽奖 | 对应的页面 |

## 动效

- 进场：积分面板弹出，任务卡片依次弹出。
- 常驻：只有可开的宝箱晃。
- 点击：开宝箱 → 有卡先翻卡（共用的新卡亮相）→ 再弹开奖窗；关掉后页面重画，滚动位置不变。

## 参考结论

同类休闲游戏的每日任务普遍是「任务列表 + 活跃度进度条 + 几档宝箱」，再叠一条周进度。取这个结构，因为玩家一眼就懂。不取的：每项任务单独点「领取」（多点 6 次，没有多出的乐趣，改成做完自动记分，只有宝箱要点）；任务直接发金币（奖励分散，不好算账，改成全放在宝箱里）；用钻石刷新任务（没有第二种货币）。

## 验收点

1. 进页面 3 秒内能看出今天拿了多少分、还有哪几项没做。
2. 可开的宝箱一眼能和没到的、开过的分开；开完红点消失。
3. 每个「前往」都到得了能做这项任务的地方，做完回来这张卡片变成对勾、积分条长了。
4. 6 张卡片在 1334 高的屏上一屏放得下，最后一行不贴着屏幕底。
5. 中英文下文字都不出框。
