# UX 规格：任务中心

状态：**用户 2026-11-16 让先写代码，规格同时写；外壳做完在 Mac 上截图验收**。实现在 `pages/tasks.ts`，玩法见 `docs/01` §5.9。

## 玩家目标

看今天还差哪项任务没做，点一下去做；有宝箱就开。

## 主次层级

- 主行动：可以开的宝箱（晃动、带红点）。没有可开的宝箱时，是第一条没做完任务右边的「前往」按钮（绿，130×80）。
- 次行动：其余任务的「前往」；点没到档的宝箱看里面有什么。
- 信息：今日积分、本周积分、离周一重置还有几天、每项任务的进度和积分。

- 页签页：没有返回键，不显示顶栏（金币、生命在这页用不到）。
- 1334 高的屏一屏能看到 5 行多，第 6 行滑一下；更高的屏 6 行全在。没做完的排前面，做完的沉到后面。
- 「前往」在右手拇指够得到的一侧。

## 状态

| 状态 | 表现 |
|---|---|
| 任务没做完 | 蓝色行，进度条和「N/目标」，右边积分牌 +「前往」 |
| 任务做完 | 玻璃底的行，进度条满，右边换成对勾，排到后面 |
| 宝箱没到档 | 灰色、关着；点了弹出里面有什么（只看，不发） |
| 宝箱可开 | 彩色、隔一会晃一下、右上红点；底栏任务页签亮红点 |
| 宝箱已开 | 开着的宝箱图 |
| 未解锁（第 11 关前） | 页签灰色带锁，点进去是共用的锁页：「第 11 关解锁」+ 本周最后一档宝箱的内容 |
| 跨天 / 跨周 | 再进页面时任务换新、积分清零；没有单独提示 |

## 「前往」去哪

| 任务 | 去处 |
|---|---|
| 过关、救鱼、连击、用技能 | 直接开始当前这一关（没命时走原有的生命弹窗） |
| 看广告 | 商店（看广告领金币在那里） |
| 每日挑战 / 抽奖 / 家园建造 | 对应的页面 |
| 分享 | 当场调平台分享，成功就记上，留在本页 |

## 动效

- 进场：两块积分面板、任务行依次弹出（和别的页签页一样）。
- 常驻：只有可开的宝箱晃。
- 点击：开宝箱 → 有卡先翻卡（共用的新卡亮相）→ 再弹开奖窗；关掉后页面重画，滚动位置不变。

## 参考结论

同类休闲游戏的每日任务普遍是「任务列表 + 活跃度进度条 + 几档宝箱」，再叠一条周进度。取这个结构，因为玩家一眼就懂。不取的：每项任务单独点「领取」（多点 6 次，没有多出的乐趣，改成做完自动记分，只有宝箱要点）；任务直接发金币（奖励分散，不好算账，改成全放在宝箱里）；用钻石刷新任务（没有第二种货币）。

## 验收点

1. 进页面 3 秒内能看出今天拿了多少分、还有哪几项没做。
2. 可开的宝箱一眼能和没到的、开过的分开；开完红点消失。
3. 每个「前往」都到得了能做这项任务的地方，做完回来这一行变成对勾、积分条长了。
4. 6 行任务在 1334 高的屏上能滑到最后一行，不被底栏挡住。
5. 中英文下文字都不出框。
