# UX 规格：主页（重做）

状态：版面 2026-11-16 由用户确认（去掉底栏、六个入口加选关键、三个气泡）。实现在 `pages/home.ts`，规则以 `docs/01` 5.3 为准。「现状问题」「参考结论」两节是重做前写的，留作背景。

## 玩家目标

打开游戏，一点就进入下一关。其它一切都是次要的。

## 现状问题

- 标题是一行纯金色字，没有造型，像占位。
- 四个气泡里的小鱼散在中间，没有主角，画面没有焦点。
- 左右两个入口方块和中间的鱼互相抢视线。
- 大绿按钮只写「第 N 关」，缺少「开始」的号召感。

## 参考结论（同类休闲消除游戏的共同做法）

- 标题做成一个 **Logo 图**：描边立体字加一个小图案，占上方约 1/5，不是一行文字。
- 画面中央只有 **一个主角**，体型大，有呼吸或摆动的常驻动效；其余装饰很小很淡。
- **一个** 压倒性的主按钮，在下半屏中偏下；文字写动作（「开始」），关卡号作副信息。
- 次级入口（签到、每日、抽奖）是 **同尺寸的小图标**，成组靠边，带红点提示；不和主角抢。
- 顶栏只放资源。（原来写的「底栏放页签」2026-11-16 取消：不要底栏，系统入口也放主页。）
- 不取：任何一款的具体造型、配色、布局坐标。

## 布局（750×1334）

```
┌──────────────────────────────┐
│ [头像] [● 1280 +] [♥ 3] [设置]│ 顶栏，中线 y = 顶 − 76（只有主页有）
│                              │
│ [签到]                [商店] │ 入口：格子 112 + 标签牌 124×40，
│           ╭────────╮         │ 标签牌离屏幕边 22；第一行中线 顶 − 282，行距 168
│ [每日]    │ 大气泡 │  [收藏] │ 大气泡（鱼 230）在两列之间
│           ╰────────╯         │
│ [抽奖]                [任务] │
│       ╭───╮       ╭───╮      │ 两个小气泡（鱼 140）落在入口的下方
│       ╰───╯       ╰───╯      │
│                              │
│  ┌──────────────┐ ┌────┐     │ 「开始」430×156 + 右边的「选关」键 140×156，
│  │ 开始  第 N 关 │ │选关│     │ 底边离屏幕底 50（有底部安全区时再让开）
│  └──────────────┘ └────┘     │
└──────────────────────────────┘
```

- 没有底栏：左列是每天来点一下的活动（签到、每日挑战、抽奖），右列是常驻的系统（商店、收藏、任务）。
- 「选关」和「开始」放在一起：选哪一关和开始是一件事。
- 第一排入口离顶栏空 82（2026-11-18 用户：原来 18 太靠上）。
- 入口的格子、图标、标签牌大小都一样；未解锁的灰显加小锁，标签写「第 N 关解锁」，点进去是锁页。
- 气泡的位置和大小在 `game_ui.json` 的 `homeDeco.school`（相对顶栏和开始按钮之间那一段的正中）。
- 更高的屏：入口行距最多拉到 1.2 倍，气泡最多放大到 1.12 倍、上下拉开。
- 挑战关在主按钮右上角压一块红色「挑战」小标。

## 动效

- 进场：六个入口依次弹出，然后是主按钮和选关键（总时长不超过 0.8 秒）。
- 常驻：气泡的待机动画和水里的光（见 `docs/01` 5.3）；主按钮缓慢呼吸缩放 ±3%。
- 点击：按下缩 0.95，松手回弹。

## 验收点

1. 三秒内看出「开始」是主按钮。
2. 画面只有一个视觉焦点（主角），标题像一个 Logo。
3. 次级入口大小一致、不抢戏。
4. 主页在 750×1334 和 750×1624 两种比例下都不挤、不留大空洞。
5. 所有可点区域不小于 88×88。
