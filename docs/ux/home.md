# UX 规格：主页（重做）

状态：**待用户确认**。确认前不改 `src/ui/main_page.gd`。

## 玩家目标

打开游戏，一点就进入下一关。其它一切都是次要的。

## 现状问题

- 标题是一行纯金色字，没有造型，像占位。
- 四个气泡里的小鱼散在中间，没有主角，画面没有焦点。
- 左右两个入口方块和中间的鱼互相抢视线。
- 大绿按钮只写「第 N 关」，缺少「开始」的号召感。

## 参考结论（同类休闲消除游戏的共同做法）

- 标题做成一个 **Logo 图**：描边立体字加一个小图案，占上方约 1/5，不是一行文字。
- 画面中央只有 **一个主角**，体型大，有呼吸或摆动的常驻动效；其余装饰很小很淡。
- **一个** 压倒性的主按钮，在下半屏中偏下；文字写动作（「开始」），关卡号作副信息。
- 次级入口（签到、每日、抽奖）是 **同尺寸的小图标**，成组靠边，带红点提示；不和主角抢。
- 顶栏只放资源；底栏放页签。
- 不取：任何一款的具体造型、配色、布局坐标。

## 布局（750×1334，主页内容区约 y 100–1160）

```
┌──────────────────────────────┐
│ 顶栏：金币 · 生命 · 设置      │ 常驻，不属于本页
│                              │
│        [ LOGO 啵啵救援队 ]   │ y 130–330，宽 560，居中
│                              │
│  [签到]                [抽奖] │ 小图标 96，距边 32，y 360 起
│                              │ 竖排，两侧各 1–2 个
│        ╭──────────╮          │
│        │ 主角气泡 │          │ 直径 400，中心 y≈620
│        │  + 大鱼  │          │ 只有这一只，其余小鱼 3 条，
│        ╰──────────╯          │ 直径 90–120，贴边缘慢漂
│                              │
│   ┌────────────────────┐     │
│   │       开 始        │     │ 560×128，y≈900，绿色
│   └────────────────────┘     │ 下方一行小字「第 65 关」
│                              │
│ 底栏：五个页签                │ 常驻
└──────────────────────────────┘
```

- 主按钮在屏幕约 2/3 高度处，拇指可达。挑战关主按钮换橙色，上方加「挑战」小标。
- 次级入口去掉方块底板，改为圆形图标加下方 22 号小字；未解锁灰显加小锁，点击提示「第 N 关解锁」。

## 状态

| 状态 | 表现 |
|---|---|
| 默认 | 如上 |
| 未签到 | 签到图标红点 + 轻晃 |
| 功能刚解锁 | 保留现有「新功能」弹窗 |
| 挑战关 | 主按钮橙色，加「挑战」标 |
| 没有生命 | 点「开始」弹补充生命，不进关 |

## 动效

- 进场：Logo 从上落下弹一下，主角放大弹出，按钮最后淡入（总时长不超过 0.8 秒）。
- 常驻：主角上下漂浮；主按钮缓慢呼吸缩放 ±3%。其余装饰不加常驻动效。
- 点击：按下缩 0.95，松手回弹。

## 文案

| 键 | 中文 | English |
|---|---|---|
| UI_START | 开始 | Play |
| UI_LEVEL_SUB | 第 %d 关 | Level %d |
| UI_TITLE | 啵啵救援队 | Pop Pop Rescue（Logo 图内的字，仍保留键用于无障碍文本） |

## 美术需求（Codex）

见 `art/briefs/batch4_home.md`：Logo、主角大气泡（可沿用现有气泡）、主页水底背景增强。

## 验收点

1. 三秒内看出「开始」是主按钮。
2. 画面只有一个视觉焦点（主角），标题像一个 Logo。
3. 次级入口大小一致、不抢戏。
4. 主页在 750×1334 和 750×1624 两种比例下都不挤、不留大空洞。
5. 所有可点区域不小于 88×88。
