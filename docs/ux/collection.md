## 与 `docs/01` 的差异（实现待改）

本规格下文记录的是现有实现。`docs/01` §5.0、§5.4 的定稿比它多三点，改代码时一并更新本规格：

- 六册一册一个海域：晨光沙滩、珊瑚花园、海草森林、沉船湾、水晶洞窟、海底宫殿，卡按归属表分。
- 救援记录：局内出场的 46 种，卡片上加一行「已救 N 只」和到下一档的进度；救够 30 / 100 / 300 只时卡片上出「领取」按钮。没有这张卡时是剪影加「已救 N 只」。
- 主页入口红点：册子大奖、终极大奖、救援奖励任何一种可领都亮。

## 玩家目标

看自己的收藏进度，把集齐的册子大奖领走。

## 主次层级

- 主行动：集齐的册子上的绿色「领取」按钮（160×70，脉动）。没有可领的时候，主行动是点开一册看卡。
- 次行动：① 总进度条右端的终极大奖宝箱（集齐 6 册后可点，脉动）；② 册子内的「返回」；③ 点册子卡片进入。
- 信息：总进度「已收集 N/237」、每册进度条和 N/39（最后一册 N/42）、「第 N 关解锁」、册子大奖图标。

## 布局（750×1334，页面是一整块深色底板，内容区 y 约 100–1160）

册子列表（首页）：两列卡片，不滚动（用户 2026-11-16：原来是一行一行的列表，改成卡片）

```
[返回]        [ 收藏 ]                      页头（各子页面同一个）
[卡] 24/237 [=====进度条=====]      [宝箱]   白色面板 690×130（宝箱在右端，终极大奖）
┌──────────────┐ ┌──────────────┐           册子卡片：两列、三行，占满面板下面的地方（最高 300）
│   [封面]   ✓ │ │   [封面]     │           从上到下：封面（里面是这一册最稀有的鱼）→ 册名 →
│   晨光沙滩   │ │   珊瑚花园   │           进度条（数字写在条上）
│  ━ 10/10 ━  │ │  ━ 4/10 ━   │
└──────────────┘ └──────────────┘ ×6
```

- 集齐没领的：进度条换成绿色「领取」按钮（脉动）；领过的：右上角一个对勾。
- 没开放的：封面变灰、鱼变剪影，下面一行小锁 + 金色「第 N 关解锁」，不可点。
- 整张卡片是点击区（进入这一册）；「领取」按钮在卡片内，单独响应。

一册内：

```
[返回 150×70]      册名             y 24
┌ 大奖条（宽 698，高 120）─────────┐ y 112
│ 大奖  [金币 1000] [技能×4 各 ×1]   [领取 / 已领取 / 3/10] │
└────────────────────────────────┘
滚动区 y 250 起：3 列，每行 214 高，每行下面一块木架
每格：鱼缸 176 + 鱼 92 + 名字（稀有度颜色，24 号）
```

- 大奖条里每种技能各一个图标，数量都是册子配置的 `tools`。
- 不显示重复张数：重复卡开出来就自动换成金币（`dupeCoins`），格子上再写「4」会让人以为攒着能用（用户 2026-11-17 指出，已去掉角标）。
- 不在关卡里出场的卡（只能开宝箱得）没有救援进度：同一个位置放一块稀有度小牌（按稀有度上色），每格下面都齐（用户 2026-11-17）。

## 状态

| 状态 | 表现 |
|---|---|
| 册子未开放 | 封面变灰、鱼变剪影，下面小锁 + 金色「第 N 关解锁」，卡片不可点 |
| 册子进行中 | 进度条 + N/39；右侧宝箱图标 |
| 集齐未领 | 「领取」按钮脉动；主页的收藏入口有红点 |
| 已领取 | 金色「已领取」 |
| 终极大奖可领 | 总进度右端宝箱脉动，可点 |
| 终极大奖已领 | 宝箱换成打开的样子，不再可点 |
| 卡片没有 | 鱼缸变淡、鱼是深蓝剪影、名字写「？？？」 |
| 卡片已有 | 鱼轻轻摆动；名字按稀有度上色 |
| 整个功能未到第 6 关 | 不进本页，显示锁页（`LockedPage`），带终极大奖预览（金币、技能、无限生命、头像框） |

## 交互

- 点册子卡片 → 进入这一册（页面重建，状态存在静态变量里，从主页切走再回来仍在这一册）。
- 点「领取」→ 入账 → 开奖弹窗（`MetaPopups.prize_reveal`，标题「大奖」）→ 点「收下」后刷新页面和红点。
- 终极大奖奖品多一项「头像框」，领后主页头像和个人资料弹窗外圈出现金色框。

## 动效

- 进场：册子卡片依次弹出（间隔 0.05 秒）；已有的鱼在鱼缸里摆动。
- 常驻：只有「领取」按钮和终极大奖宝箱的脉动（同屏最多这两类）。
- 点击反馈：按钮标准按下缩放。
- 新卡获得的翻面亮相不在本页，见 `ui/popups.ts` 的 `revealCards`：卡背朝上弹出 → 翻转 → 正面（生物大图、名字、稀有度颜色光圈）→ 史诗以上加金光和火花；重复卡写「已拥有，换 N 金币」。卡面翻完后出绿色「继续」按钮。

## 参考结论

集卡类游戏的共同做法：总进度放顶部、卡册分章节、未得到的卡用剪影、集齐一章有额外奖励。我们取「分册 + 剪影 + 集齐领奖」的结构；不取任何一款的卡面样式、册子封面和排版。

## 验收点

1. 一眼看出总进度和哪一册有奖可领。
2. 未开放的册子明确写着第几关解锁，点了不进入。
3. 一册内能数出 39 张卡（最后一册 42 张），3 列排满、最后一行不缺；没有的是剪影。
4. 领取 → 开奖 → 收下后，红点和「已领取」同步更新。
5. 所有可点区域不小于 88×88（册子卡片整张可点，满足）。
