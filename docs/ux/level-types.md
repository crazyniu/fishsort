## 1. 局内顶栏的关卡号

| | 普通关 | 难关 | 超难关 |

| 关卡号的字 | 照现在（30 号白字、深色描边） | 白字，描边深红橙 `#B23A0E` | 白字，描边深紫 `#4C1D95` |

- 小牌子：高 40 的圆角胶囊（平面纯色，和整套界面一样），左边 26 的白色图标，右边 22 号白字；离关卡号 8。
- 关卡号和小牌子当成一组，按现在的规则居中、碰到左边的鱼数条往右让；微信的胶囊那一行同样。按最长的「第 360 关」+「超难」量过才算数，不缩字。
- 每日挑战不出小牌子。

## 2. 开局横幅

- 难关、超难关进关时（新机制说明之后、开局小卡之前，开局小卡见 `docs/ux/route-2026-11-19.md` 第 2 节），屏幕中间偏上一条横幅，难关红橙色、超难关紫色，和小牌子同色。
  - 大字（48 号）「困难关卡！」/「超难关卡！」，左边同一个图标放大到 64。
  - 下一行小字（26 号）「过关 60 金币」/「过关 90 金币」。
- 从左滑入、停 1.2 秒、往右滑出，然后缩成顶上的小牌子（飞过去）。点哪里都能马上收起；横幅不挡点击。
- 音效：比开局声低一点的「咚」。同一关重打也出。

## 3. 选关页

- 现在难关是紫色圆牌 + 左上角一面小旗。改成：难关**红橙色**圆牌 + 左上角小火苗；超难关**紫色**圆牌 + 左上角鲨鱼鳍。普通关照现在（蓝）。
- 当前关（绿）、没解锁（灰 + 锁）照旧盖在上面：当前关是难关时，圆牌照样是绿的，但左上角的火苗 / 鲨鱼鳍还在，提前看得到。
- 海图（按海域的大卡片）不画每一关，不改。

## 4. 结算页

- 过关金币那一格前面加同色的小牌子：「困难 +60」「超难 +90」；普通关照现在。

## 5. 图标

- **火苗**（难关）、**鲨鱼鳍**（超难关）：白色平面小图标，和 `kit/ic_*` 一套风格。先用代码画（`tools/art/kit.mjs`）。如果 Codex 画出来更好看再换，记进待做清单。
- 不用骷髅：和可爱的海底风格不搭。鲨鱼鳍有「危险」的意思，又是海里的东西。
- 选关页的红橙色圆牌 `skin/f_node_orange` 照 `f_node_purple` 的画法用代码画。

## 参考结论

同类的消除、排序类游戏：

- 主线里的难关都用醒目的颜色标出来（常见红色、紫色），配骷髅、火焰之类的图标和「困难」「超难」字样。
- 开局有一条「困难关卡」横幅提醒，地图或选关页上的关卡点也换色，没进关就看得出。
- 难关奖励更多，失败后常常更容易买道具。

我们取：颜色、图标、字三样一起区分，色盲也分得出。图标用火苗和鲨鱼鳍，不用骷髅。

## 验收点

1. 进关 1 秒内看得出这关是普通关、难关还是超难关。
2. 只看颜色、只看图标、只看字，都分得出三种关。
3. 关卡号加小牌子，在 750 宽的屏幕和微信胶囊那一行都不挤、不缩字（按第 360 关量）。
4. 选关页上不进关就看得出哪关难、哪关超难。
5. 结算页金币和关卡类型对得上：30 / 60 / 90。
