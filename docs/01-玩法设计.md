# 01 玩法设计

## 0. 设计原则（先读这一节）

1. **收入靠广告，新用户靠分享。** 所有系统都围绕两件事设计：让玩家习惯看激励视频；分享只做普通转发、不给奖励（微信禁止诱导分享，5.8）。
2. **金币要花得掉。** 金币只有一种，来得快、去得也快：买生命、买技能、抽奖、开缸位。金币花完，玩家才会去看广告。
3. **退出有代价。** 中途退出、重试、失败都扣生命，逼玩家在卡住时用技能、看广告复活，而不是无成本重开。
4. **爽。** 每一次点击、入缸、满缸、连击、结算都要有声音、有动画、有数字跳动。动画不挡操作。
5. **好找。** 同一关里的生物一眼能分清（颜色和轮廓都不同）。
6. **文字摆正。** 汉字和单词不倾斜、不旋转、不用斜体；数字允许轻微倾斜。

一句话：海洋生物被困在气泡里。点它，送进要它的鱼缸；一缸收满 3 只，鱼缸连同里面的生物一起消失，换下一缸。全部救出过关。

目标用户：泛休闲玩家，单局 2–4 分钟，单手竖屏，零文字教学也能上手。

## 1. 局内界面

```
┌──────────────────────────┐
│ (🐟 6/63)        (第 3 关)│  左：已救/总数   右：关卡号。局内不显示金币
│ [缸] [缸] [＋] [＋]       │  木架上 4 个缸位，默认开 2 个，未开的是暗缸加绿色「＋」
│ ▤▤▤  ▤▤                   │  每个缸前面叠着订单卡：一张卡一条要的鱼，进一条揭一张；空缸里不画鱼
│      [ ][ ][ ][ ][ ]      │  暂存槽 5 格，居中、低调；只剩 1 格时那一格红框闪
│                          │
│        气 泡 场           │  占屏幕 60%，掉落关里气泡从上方落下
│                          │
│ [技能][技能][技能][技能] ⚙│  技能键 + 设置；未解锁的显示灰锁和「第 N 关」
└──────────────────────────┘
```

- 「第 N 关」在挑战关显示为金色。
- 金币只出现在弹窗里（开缸位、买技能、买生命）和结算页。
- 所有弹窗共用一套样式，见 `docs/03` 的「弹窗」。

## 2. 核心规则

### 2.1 名词

| 名词 | 定义 |
|---|---|
| 生物 | 鱼、海星、螃蟹、鲨鱼等，规则上完全等价，下文统称「鱼」 |
| 气泡 | 场上的容器，内含 1–5 条鱼 |
| 可点气泡 | 已在场上、没被更高层气泡压住、没被锁链或冰封挡住的气泡。只有可点气泡里的鱼能点 |
| 鱼缸 | 顶部容器，带一张订单：目标鱼种和容量（默认 3） |
| 订单队列 | 本关所有订单的有序列表，关卡数据里写死 |
| 暂存槽 | 5 格；第 121 关起 4 格（2026-11-17，见第 4 节）。点了当前没有缸要的鱼，就进暂存槽 |
| 回流位 | 吹泡把暂存槽的鱼吹回来后停靠的一排小气泡，在气泡场下沿，可直接点，不压住也不被压住 |
| 候场队列 | 掉落关里还没落到场上的气泡，玩家看不到 |

### 2.2 一次点击的结算顺序

1. 玩家点一条可点气泡里的鱼（点的是鱼，不是整个气泡）。
2. 若有激活的鱼缸要这种鱼且未满 → 鱼飞入该缸（多个缸都要时进最左边的）。
3. 否则 → 鱼进暂存槽最左空位。
4. 该气泡若已空 → 破裂，重新计算可点气泡；掉落关里从候场队列补落新气泡（见 2.5）。
5. 任一鱼缸满 → 该缸连同里面的鱼消失，从订单队列取下一张订单补位（队列空则缸位空置）。
6. 新缸出现后，暂存槽里匹配的鱼自动按从左到右飞入。回到第 5 步，直到没有变化（连锁）。
7. 判定胜负。

订单卡固定在木架上，新订单生效时立即换卡。动画期间允许继续点击（逻辑立即结算、表现追帧），保证手感不卡。

### 2.3 胜负

- **胜**：场上、候场队列、暂存槽、回流位都没有鱼。
- **负**，三种情况任一：
  - 结算完成后暂存槽仍是满的；
  - 限时缸倒计时归零；
  - 还有鱼，但回流位是空的，且场上没有一条能点。
- 倒计时在弹窗、广告、切后台期间暂停。
- 失败时先弹**复活弹窗**（每关 1 次，看广告）：效果等同一次「吹泡」；因限时缸失败则 +30 秒；因无鱼可点则解开全部锁链与冰封。放弃复活才算失败，扣 1 条生命（见 5.1）。

### 2.4 鱼缸位

| 缸位 | 开启方式 |
|---|---|
| 1、2 | 默认开启 |
| 3、4 | 点「＋」弹窗：300 金币，或看广告。先开 3 再开 4 |

**加开的缸开一次管到这关结束**（用户 2026-11-18 改回：买过的缸被换掉以后不要再让人重新买）：开出来的缸装满送走后，下一个订单照样补进这个缸位。`economy.json` 的 `bowlSlotOnce` 是开关，现在 `false`；改成 `true` 就是「加开的缸只装一缸」——装满送走后缸位收起来、「＋」重新出现、要用再买（同一天早些时候定过这一版，为了不让开一个缸就稳过，`docs/02` 第 0.1 节）。关卡生成用的机器人仍按「只装一缸」量（`core/solver/careful.ts`），所以真人开缸以后比报告里写的更容易过。

只有队列里还有待接订单才显示可开的「＋」；最后一张订单上架即收起入口。开启只在本关有效。多开一个缸 = 同时接更多订单 = 明显变简单，是主要的广告点和金币去向。开了以后新缸 0.3 秒后就落下来（约 0.65 秒到位，不等满缸送走那段演出；用户 2026-11-17 嫌慢，减半）。

但**开缸不等于过关**：关卡按「第 3 缸让胜率明显上升、但后期仍可能失败」生成（目标见 `docs/02` 第 2.1 节）。这样第 4 缸也有用，技能和复活也还有用武之地；如果开一个缸就稳过，玩家卡关时只会点这一个按钮，其它广告点和金币去处都没人用。

### 2.5 掉落

- **第 1–25 关**：气泡一次摆完，一层压一层，被压住的看得见但点不了。
- **第 26 关起**：掉落关。关卡有一个「场上容量」，开局落下容量个气泡，其余在候场队列里看不见；每破一个气泡，队列里的下一个从屏幕上方落下。左上角总数包含候场的鱼，所以玩家知道还有多少，但不知道是什么。
- **挑战关**：场上容量更小、候场更多，未知更多。
- 落点只是表现：逻辑上候场队列是有序的、确定的，位置由界面层摆放，不影响规则与可解性。
- 掉落关不再用「高层压低层」，未知信息全部来自候场队列。

### 2.6 自动收尾与提示

- **自动收尾**（2026-11-17 用户定：最后几个「无脑点」的气泡不让玩家再点）：还没完成的缸都已经摆上架（后面没有新缸），并且照规则每次点一条能直接进缸的鱼、一路点到赢、中间一条都不进暂存槽，并且还没进缸的鱼（气泡、回流泡、暂存槽里的）只剩 3 条以内（用户 2026-11-17 定，`autoFinish.maxLeft`）——这时不用玩家再点：最后一步之后停 0.5 秒，鱼每 0.2 秒自动进一条（仍计连击），随后进过关演出；自动收尾接管时冻结整关和限时缸倒计时，按已确定的顺序入缸。被压住、锁链、冰封的照规则在过程中解开。判断在 `core/rules/autoFinish.ts`，时间和条数在 `game_ui.json` 的 `autoFinish`。（原来写的是「只剩一个种类时」，Cocos 版一直没做。）
- **提示**：玩家发呆 7 秒（前 3 关 2 秒），在一条点了能直接进缸的鱼上套呼吸光圈。只提示整步都能安全入缸的鱼（含结伴鱼），无合适目标时收起光圈。没显形的迷雾鱼不给提示。

## 3. 爽感：动画、连击、结算

这一节是验收标准。交付时按时间点连续截图自检并给用户看；声音靠用户反馈。

### 3.1 基础动画（每一步都要有）

| 时机 | 表现 |
|---|---|
| 开局 | 载入页淡出。没有遮挡的关卡：气泡从场地上沿一个接一个落下来，落在地上或别的气泡上、压扁一下弹回，堆成一堆。有遮挡的关卡：气泡按关卡摆法依次弹出，再由重力压实 |
| 点鱼 | 鱼原地一弹（放大再回落），点击处一圈水波，短促「啵」声 |
| 鱼飞进缸 | 沿弧线飞约 0.4 秒，身后拖一条蓝白闪光尾迹；多条鱼依次出发 |
| 入缸 | 缸口溅起一把小气泡和一圈扁的涟漪，鱼缸轻轻一弹，缸里的目标鱼和数量牌跳一下；清脆的一声加水花声（每次音高略有不同） |
| 鱼进暂存槽 | 短弧线落入，槽格轻弹，声音比入缸低沉 |
| 气泡破裂 | 碎成几粒小泡沫向外散开 |
| 满缸 | 订单卡打勾 → 三条鱼在缸里抖动约 0.5 秒 → 鱼缸发白光膨胀 → 炸成光点，整排木架扫过一道亮光 → 新缸和新订单卡从上方落下。全程约 1.5 秒 |
| 满缸夸奖 | 缸旁跳出「不错！」「真棒！」「太强了！」，摆正，带描边和弹跳 |
| 暂存槽告警 | 只剩 1 格时该格红框闪动，伴随低频提示音 |
| 新气泡落下 | 从场地上沿落下来（落点在刚破的气泡上方附近），掉在堆上，沿着别的气泡滚到位，落地压扁一下、轻轻「咚」一声 |
| 气泡破了之后 | 压在上面的气泡受重力落下来、滚进空出来的位置 |
| 常驻 | 气泡的泡膜像果冻一样慢慢鼓一下、扁一下，彩虹边沿着泡边流动，隔一两秒某个气泡的高光闪一颗小星（被压住的不带流光）；背景里一直有小气泡从下往上冒、左右摆着；每个鱼缸里也有小气泡从缸底冒到水面（用户 2026-11-16） |
| 弹窗 | 缩放回弹着出现，背景压暗 |

**气泡的重力**（用户 2026-11-16 定）：场上所有气泡都受重力，像一堆有分量的球——上面的压着下面的，下面的破了上面的就落下来，落在别的气泡上会沿着它滚下去，不会穿过别的气泡直接到底。这只是画面：谁压着谁（遮挡）仍然由关卡数据决定，不看画面位置。所以有遮挡的关卡里，互相压着的一对之间连一条「弹性带」：两个圆心的距离只能在设计距离的 60%–100% 之间，压着的始终压着，画面上的遮挡和规则一致；但这一对能转、能挪，整堆会滚进空当里压实（用户 2026-11-16：原来整组焊死成一块，堆里留着空）。其中一个破了，连着它的带就没了，上面的落下来。开局前先在内存里试算一遍，把气泡整体放大或缩小到「压实后刚好堆满场地」（半径上限 150），所以不管这关气泡多少，场地上面都不会空着一大截。鱼缸坐在木架上（缸底压着木架上沿），数量牌贴在木架正面。

### 3.2 连击

- **规则**：点到的鱼直接进缸算一次命中；2 秒内再次命中连击 +1；鱼进了暂存槽或超时清零。暂存槽里的鱼自动补进新缸也算命中。
- **档位与金币**（数值在 `economy.json` 的 `combo`）：

  | 连击数 | 档位 | 主色 | 每次命中金币 |
  |---|---|---|---|
  | 4–6 | 不错 | 蓝 | 1 |
  | 7–9 | 漂亮 | 金 | 1 |
  | 10–14 | 太强了 | 红 | 1 |
  | 15+ | 无敌 | 紫 | 2 |

  4 连开始算连击（用户 2026-11-16 定：先是 6 连太难触发，改成 3 连后又太容易，随便点三下装满一缸就出，所以定在 4——要连到下一缸才算）。比最初起算早、命中次数多，每次的金币相应调低，每关上限不变。

  每关连击金币上限 12（2026-11-18 金币整体缩小 5 倍，见第 6 节）。连击的回报主要是爽感和送卡，金币只是点缀：过一关的金币主要来自过关本身（见第 6 节）。
- **位置**（用户 2026-11-16 定）：不带底板的大号「连击 ×N」艺术字，浮在暂存槽那一排的正中，**没有倒计时条**（用户 2026-11-16 定：不要底板、不要进度条）；连击金币每涨一次从它右边飘一个「金币 +N」；断连后抖一下往下掉、淡出。顶栏不变（进度、关卡号、设置都一直在）。不在场地中间常驻大数字，不挡气泡（用户 2026-11-15 定）。
- **连击送收藏卡**：连击数第一次到 10 / 15 / 20 时各掷一次，30% / 60% / 100% 送 1 张收藏卡，每关最多 1 张。当场飞出提示，不打断操作，结算时列出。收藏开放（第 6 关）前连击不送卡。
- **最高连击奖**：本关最高连击 ≥ 6（不跟着起算数降，3–5 连不给），结算额外给「最高连击 × 2」金币，上限 40。
- **表现**：连击要爽，让人觉得整个屏幕都在跟着动，画面、声音、震动一起升级（用户 2026-11-16 定）。同一天又定了一条底线：**不盖鱼缸和目标卡、不盖气泡、不影响操作**——所以鱼缸上炸的光、四边光框、升档时的闪光、放射光、冲击波、彩纸、烟花、往上冒的光点，全都垫在玩法后面那一层（气泡、鱼缸、目标卡画在它上面），动效本身不变。「连击」、数字和四档夸奖词都是 Codex 画的艺术字（中文用图，其它语言用字）。
  - **蓄势（第 2、3 击）**：连击计的位置冒小号的「×2」「×3」；轻震一下。
  - **每次命中（4 连以上）**：连击计的数字从 2 倍砸下回弹（可轻微倾斜），连击字整块顿一下；鱼缸背后炸一圈档位色的柔光、光环和火花；整个场面瞬间放大一点再弹回；四边光框闪到最亮；轻震一下。
  - **常驻（4 连以上）**：屏幕四边按档位色发光呼吸；玩法后面垫一层整屏的放射光慢慢转；光点和小气泡从屏幕底下往上冒（都垫在玩法后面）。档位越高越亮、转得越快、冒得越密。
  - **升档**：夸奖艺术字（宽不到屏幕的四成，落在暂存槽那一排，不伸到上面的鱼缸、目标卡和下面的气泡上，用户 2026-11-16 定）从大砸下（背后档位色柔光和慢慢转的爆炸星，**不用飘带**，用户 2026-11-16 定）。落地的一刻：全屏闪档位色、放射光炸开到整屏、两圈冲击波、屏幕震、全场气泡从夸奖词往外鼓一圈、鱼缸依次跳一下、两个下角往中间喷彩纸；红档和紫档再在场地里炸 3 / 5 发烟花。约 1 秒后夸奖词缩小飞进连击计。蓝、金档中震，红、紫档重震。
  - **声音**：每条鱼进缸都有进缸声（清脆一声 + 水花）；连击起算（第 4 击）后每一击再叠一声「叮」（低频鼓点 + 铃音），沿五声音阶一击升一个音，共 11 级，到顶后停在最高音。升档音分四档：竖琴往上滑 → 颤音琴和钢片琴的和弦 → 钟琴点几个亮音；档位越高和弦越高，依次加小镲、铜管和吊镲、定音鼓和小号。断连不出声（用户 2026-11-18：原来两个往下走的低音像「叮咚」，不好听，去掉）。
  - **断连**：数字变灰，连击计抖一下往下掉并淡出；光框、放射光、光点一起收掉。
  - 震动在设置里能关；音效和震动的强弱都跟着档位走，不单独配置。

### 3.3 过关结算

- 最后一缸消失后停半拍 → 闪白、放射光炸开、屏幕震、两个下角喷彩纸、四发烟花约 1 秒（重震一下）→ **只出一个结算页**，同屏完成，不分段。
- 结算页：横幅从大砸下，落地时屏幕震、金色放射光炸开、两个下角往上喷彩纸铺满全屏 → 宝箱原地弹出 → 三颗金星从宝箱转着飞上去依次落位（灰色星位先在；三颗星三个音 do、mi、sol，每颗落位轻震）→ 宝箱越晃越大、白光一闪弹开（放射光、冲击波、重震），光芒放大，两条鱼跳一下 → 奖励条从下面滑上来，金币从星星处飞进金币图标，数字滚动（过关 + 连击 + 最高连击奖），滚完弹一下 → 按钮从下往上依次升起，「下一关」呼吸。播完后星星周围隔一会闪一颗星光。
- 从过关到可以点「下一关」不超过 3 秒，任何时候点一下可跳过动画直接到最终状态。
- 开出收藏卡时：稀有度越高越华丽，史诗和传说全屏闪光。

- **限时关的时间怎么定**：按机器人「不犹豫地点完」要的时间（鱼数 × 1.5 秒 + 缸数 × 1.5 秒）乘一个系数，第 61 关 0.55 倍、往后线性降到最后一关（第 360 关）0.5 倍，按 5 秒取整，最少 60 秒；**排队泡多的关再按排队泡占的比例加长**，全是排队泡的关时间翻倍（`clock.queueExtra`，用户 2026-11-18 试第 140 关：126 条鱼给 135 秒，一秒一条，来不及想先取哪条）。**时间按真人的手速定、给得短，靠连击挣回来**（用户 2026-11-17：他第 120 关 123 条鱼两分钟多打完、没用道具，而当时的倒计时是 6 分 20 秒——机器人的 1.5 秒一条估得太慢，真人约 1 秒一条；并提出「时间短一点，用连击加时间」）：第 120 关现在是 2 分 15 秒，正好是他不靠连击的用时。连击起算（4 连）以后每命中一次加 1 秒，15 连以上每次加 2 秒（`clock.comboSeconds`，按连击档位查），倒计时条弹一下、下面飘绿色的「+N」；渔网、洋流捞的鱼每条都算连击，所以用道具也能挣时间。每次加的秒数不能大于点一条鱼要的时间太多：试过 15 连以上 +3 秒，连击时倒计时越走越多，等于没有限时。（这一天里系数改过几次：1.35 → 1.1 每关限时；1.6 → 1.4 只限挑战关；最后是现在这样）（`level_curve.json` 的 `clock`，`LevelCurve.clockFor`）。系数都大于 1，机器人不会超时，关卡的胜率目标不受影响——这个时间只给真人压力；真人试玩后按实际点击节奏调系数。说明在第 65 关开局弹一次。第 121 关开局弹「暂存槽只有 4 格」，第 123 关弹「每种道具每关能用 3 次」。
- **迷雾为什么不用剪影**：同一关里生物的轮廓各不相同（`docs/03` 第 4.1 节），剪影一眼就能认出是什么，迷雾就白设了。
- **冰封为什么要画连线**：第 26 关起是掉落关，后落下的气泡位置由界面摆放，「旁边」不是逻辑上的关系。界面把冰封泡摆在它依赖的气泡旁边，并画出连线，玩家才知道该先破哪个。
- 单关最多叠加 3 种障碍；障碍种数每 5 关一个强弱节奏，新机制解锁后先密后疏，不会几十关都是同一套（`docs/02` 第 2.4 节）。

### 5.1 生命

| 项 | 设定 |
|---|---|
| 上限 | 5 条 |
| 恢复 | 每 20 分钟 1 条，满了停止计时 |
| 扣 1 条 | 失败后放弃复活；中途回主页；中途点重试 |
| 不扣 | 过关；一步没动就退出；第 1–5 关 |
| 重玩旧关 | 同样规则 |

- **生命为 0** 点开始时弹「生命」弹窗，三条路：
  1. 看广告得 1 条（`rv_life`），每天 5 次。这是主按钮。
  2. 80 金币买 1 条；300 金币补满 5 条。
  3. 等：显示「下一条 12:35」倒计时。
- **命要值钱**：一条命的金币价（80）大约是打两关的收入，所以失败、中途退出是真的有代价，玩家才会用技能、看广告复活，而不是无成本重开（第 0 节原则 3）。
- **无限生命**：作为奖品，期间不扣命，顶栏心形显示「∞」和剩余时间。来源：每日首胜 10 分钟、抽奖 15 分钟、签到第 7 天 30 分钟。
- **离开确认**：已经走过步时点回主页或重试，弹「现在离开会失去 1 条生命」，主按钮「继续玩」，次按钮「离开」。
- **防刷**：无服务器，按本地时间算；检测到时间倒退则这段不恢复，其余接受。

- **卡住时也提醒**（2026-11-17）：场上看得见的鱼（含回流位，没显形的迷雾鱼不算）没有一条能直接进缸——再点只能进暂存槽——这时技能键同样发光跳动（`Rules.noTarget`，`game_ui.json` 的 `buffer.nudgeWhenStuck`）。

## 6. 经济

只有**金币**一种货币。**设计目标：玩家的金币不够花。** 收入只靠广告（v0），玩家看广告的理由就是缺金币；一切数值都为这一条服务（用户 2026-11-18）：

1. 关卡要让玩家想花金币：难关不花金币（技能、开缸）过关概率很低，见 `docs/02` 第 0 节。
2. 花了金币只是提高过关的概率，不能一路买过去。
3. 挣的比想花的少，差额靠看广告补。**缺口要控制住**：后期挣的大约是想花的七到八成，不是差好几倍——差太多玩家直接不玩。按真人的花法算，不看广告的玩家过了前 30 关（免费技能停了）就开始缺，缺的大约是每天看几次广告能领到的金币（用户 2026-11-18）。

**账不靠心算，用 `./run.sh eco-sim` 跑**（`client/tools/economy/sim.ts`）：它调游戏里真实的发奖代码，按「一个活跃玩家每天过 10 关」跑若干天，列出一天挣多少金币、不花钱拿到多少技能、要用的技能和缸位有多少得花金币、金币不够时看几次广告。关卡难度按 `docs/02` 第 0.4 节的目标假设。改任何发金币、发技能的数值以后都要重跑。

**2026-11-18 重定**。改之前用它一量：后期玩家一天挣 3500 金币、想花的只有 700，挣的是想花的 4.9 倍；一天要用 3.9 个技能，不花钱就能拿到 6 个多；一次广告都不用看。改了三件事：

- **金币整体缩小 5 倍**（用户定）：一关挣 20，数字小了更显得金币值钱。
- **技能和开缸提价**：在缩小 5 倍的基础上再翻一倍多（技能 240 / 280 / 360 / 480，开缸 300）。

## 9. 2026-11-19 定的新方案（实施中）

用户 2026-11-19 和我一条条定下来的整套难度和奖励方案。**和前面各节冲突时以这一节为准**；每做完一块就并进对应的章节，并在下面的「进度」里勾掉。难度的方法（怎么量、怎么生成）在 `docs/02` 第 0 节。

### 9.1 原则

- **难在点击顺序**（用户原话：「难度的难点是在点击的顺序……这叫规定路线。路线对了才能通关」）。每关都有一条**规定路线**：按它走，不用任何技能、不开缸就能过。难点是同一种鱼场上有好几条能点，要看下面的气泡和别的气泡，判断先点哪一条。路线走偏了，不用道具就过不去。
- **难度 = 想清楚的人和随手点的人差多少**，用两个只看屏幕的机器人量：**随手点的玩家**不用道具的过关率是这一关的难度（普通关约八成），**想清楚的玩家**（只看架上的缸和预告，在脑子里排一排再点）每关都要九成以上能过。见 `docs/02` 第 0 节。第一版用全知的求解器量「容错」，压出来的路线要读心才走得出来（用户试第 6 关：「好像就没有正常的路线」），已经换掉。
- **收入来自失误，不是门票。** 认真想的人不花钱也能过；抢连击、碰运气、点错的人用道具救场，道具不够就花金币（以后接了广告也能看广告拿）。
- **运气只影响冒不冒险、多拿多少，不影响能不能过**：关卡布局、鱼的种类、鱼缸顺序每次进关都一样，路线才能想、能记。
- **看得到才公平**：做判断要的信息玩家都得看得到（9.3）。
- 大部分玩家只玩前 60 关（每天 10 关，约一周），所以玩法都压进前 60 关，每 5 关左右一样新东西。

### 9.2 难度曲线和三种关卡（用户 2026-11-19 定，2026-11-20 改成按海域分档）

**曲线**（2026-11-20 用户：「没必要逐关加难度……每个海域的整体难度不一样，越往后整体难度越高」「5 的倍数的关卡都是复杂的关卡，奖励比较高，剩余的每个世界的关卡难度都是平缓的，只是会有其他的玩法」「难才有意思」）。下面都是尺子（想几步的玩家，`docs/02` 0.2）不用道具、不加开鱼缸能过的比例：

- **不逐关降**：一个海域（20 关）里普通关同一个数，每进一个海域降一档。原来每关降 0.24 个点，比量出来的误差（一关 40 局，好几个点）还小，玩家分不出来；玩家感觉到的起伏来自难关 / 超难关和每关排布不同。
- 第 1–5 关新手期，第 5 关 95%。
- **头几关缓一档**：第 6–10 关普通关 55%、难关 40%（排队泡首发、开始扣命的几关；用户想第 6 关直接 40%，我建议缓两步，他同意）。第 11–20 关 45% / 32% / 25%。
- 第二个海域起 40% / 30% / 20%，往后每个海域降约 1.5 个点，最后一个海域 15% / 10% / 5%。**全游戏最难的是 5%**（用户先定 1%，随后改口「1% 概率太低了，把最难的改为 5%」）。
- **鱼的数量也跟着海域涨**（普通关）：第二个海域 66 条，每个海域多 3–6 条，最后一个海域 126 条；一个海域里一样多。用户先说「第 18 个海域 160 左右」，我建议封顶 126（通过率已经压到 15% 以下，一局再拉到四五分钟，输一次代价太大），他同意。难关比同海域的普通关多三成、最多多 24 条（最后一个海域 150 条）。
- 想清楚的玩家每关不低于 min(90%, 目标 + 40 个点)：认真想一定有路。
- 目标压不压得到要量：小关（第 6–10 关只有 39–48 条鱼）会想的玩家几乎都能过，压不到就报实际能到多少，不硬凑。

| 1（后半） | 11–20 | 45% | 32% | 25% | 48–57 |

**三种关卡**：难度的起伏、画面上的区分、鱼的多少、奖励都挂在关卡类型上，不让玩家自己选难度（见下面「为什么不做难度模式」）：

| | 普通关 | 难关（每 5 关） | 超难关（每 20 关，海域最后一关；原来叫守关） |
|---|---|---|---|
| 不用道具能过 | 这个海域普通关的那个数 | 这个海域难关的那个数（比普通关低 10 个点左右） | 这个海域超难关的那个数（再低 5–10 个点） |

| 顶上「第 N 关」 | 照现在 | 红橙色，旁边小牌子：火苗 +「困难」 | 紫色，小牌子：鲨鱼鳍 +「超难」 |
| 开局 | 照常 | 横幅「困难关卡！」 | 横幅「超难关卡！」 |
| 选关页、海图 | 照现在 | 关卡点红橙色 | 关卡点紫色 |

同一关既是难关又是超难关按超难关算。金币在 `economy.json` 的 `levelCoins / challengeCoins / bossCoins`，界面见 `docs/ux/level-types.md`。

**卡关的人**：连输 2 次、4 次自动换更容易的变体，连输 4 次送第 3 缸位（5.7），照旧，不显示「简单」字样——玩家觉得是自己打过去的。变体最多两星。

**为什么不做难度模式**（用户 2026-11-19 先提「游戏分简单、标准、困难三个模式、设置里选，难度不一样鱼的数量也不一样」，我按同类游戏的经验建议改成上面的关卡类型，用户同意）：

- 收入来自「想错了用道具补救」；能自己调简单，卡住的人先去调简单，不用道具。
- 自己调简单过的关没有成就感；系统悄悄放水，玩家以为是自己打过的。
- 三套关卡、三条曲线，每次调难度、算金币都要做三遍。
- 同类休闲解谜的主线都不让选难度，而是把难关做得一眼看得出来（红色、紫色、火苗、骷髅），奖励给得多。
- 简单 / 标准 / 困难三档只留在开发版的难度调试页（9.7），给测试时感受同一关松一点、紧一点。
- 以后想给高手选择：等主线难度调稳，给打过的关加「挑战」（用更紧的版本重打、多拿星和金币），只往难里加，不提供简单模式。现在不做。

规定路线靠结构难、不靠量大：鱼太多玩家看不过来，机器人也算不动。2026-11-20 起鱼数跟着海域涨，但封顶在普通关 126 条、难关 150 条（原来普通关 66、难关 84）。

这几样在局内怎么画（2026-11-19 做完，规格 `docs/ux/route-2026-11-19.md`）：

- **幸运泡**：进关时抽（`economy.json` 的 `lucky`：第 18 关起每次进关 35%；界面层的随机数，不进规则），抽到的气泡外面套一圈慢慢转的金圈，带奖励的那条鱼头上一个小礼物。那条鱼被取走（点的、渔网捞的、洋流带的都算）当场入账：技能图标飞到技能键上，金币、卡往顶上飞（卡留到结算页翻）。不和稀客挑同一个气泡；每日挑战、演示没有。撤销把那条鱼退回去也不再给第二次。

**看得到才公平**：加「后面几缸要什么」的预告（现在只看得到开着的 2 个缸，路线常取决于第 3、4 缸）；掉落关加「下一个落下」预告；规定路线不经过还没显形的迷雾泡——显形前去点它是玩家自己赌（赌中了连击不断，赌错进暂存槽）。

### 9.4 连击目标（取代 3.2 的「连击送收藏卡」掷骰子）

- 进关时（机制说明之后；难关、超难关在开局横幅之后）屏幕中间一张小卡「连击 ×N → 奖励图标」，下面一行「第一次过关时达到就送」，1.5 秒后缩小飞到常驻小标上。「★★★：不用道具」那一行等星级做了再加。
- 常驻小标在木架下面最右边那个缸位的目标卡位置（平时只开 2 个缸，那里空着；开到第 4 个缸就收起）：「连击」两个字 + 奖励图标 +「到目前为止最高连到几 / N」。达到时变金色、闪一下，夸一句「连击目标达成！」。打的时候连击计「连击 ×5」后面跟小一号的「/N」，达到后去掉。（规格原来写在顶栏关卡号下面，那里紧挨着鱼缸、放不下，2026-11-19 挪到这里。）
- N 从关卡文件里的参考解（想清楚的玩家赢下来的路线）现算：按路线走、中间不进暂存槽最长能连几下 × 0.75，不到 6 不出目标、最多 30（`economy.json` 的 `comboGoal`，`core/meta/comboGoal.ts`）。知道路线又点得快才够得着，诱使玩家抢快、点错。第 6 关起才有；每日挑战、重打的关、演示都没有。
- 达到就给，每关只在第一次通关时给：普通关一张普通卡、难关一张较好的卡（uncommon）、超难关一张稀有卡（rare）；收藏还没开放时换成 20 / 40 / 60 金币（算进过关金币）。技能留给首次三星，免得一关送两个技能。
- 原来「连击到某个数随机送一张卡」的掷骰子只留给每日挑战。
- 撤销不恢复连击。每次命中的连击金币照旧。

### 9.5 星级和首次三星奖励（取代 3.3 结算页「三颗星只是庆祝」）

| 星级 | 条件 |
|---|---|
| ★★★ | 一个道具都不用（技能、开缸、撤销、提示、复活都算；前 10 关免费的也算，只有强制教学那一次不算） |
| ★★ | 用了道具，不超过这一关的两星线：普通关 1 个、难关 2 个、守关 3 个 |
| ★ | 超过两星线 |

- 每关记最好成绩（`save.stars`），选关页每个过了的关下面三颗小星，拿到几颗亮几颗（加星级之前过的关没有记录，按一颗画）。海图是按海域一张卡，不画每关的星。
- 道具数 = 本关用的技能次数（含撤销、提示、救场的吹泡）+ 加开鱼缸的次数 + 复活次数；强制教学用掉的那一次不算（`GamePage.items`）。连输送的第 3 缸位不算。
- 结算页：三颗星按成绩亮，没拿到的星位留着、是灰的；横幅下面一行字，三星写「完美！一个道具都没用」，否则写「不用道具就能拿 3 星」。开局小卡多一行「★★★ 不用道具」，这一关已经三星的写「已三星」；重打的关没有连击目标，小卡只剩这一行。
- **首次三星奖励**：这一关第一次拿到三星时（第一次打没拿到、以后重打拿到也算）多送一份，越往后越多：普通关金币（一关的过关金币），难关金币加卡，守关一个技能加金币。前 20 关给得少一点，不然玩家一直不缺。数值在 `economy.json` 的 `stars`（现在：普通关 30 金币，难关 60 金币 + 一张 uncommon 卡，超难关 60 金币 + 1 个随机技能；前 20 关金币最多 30。普通关原来是 60，2026-11-20 按 eco-sim 降到 30，见 6.3）。结算页奖励条里多一格奖章 +「首次三星」，送的技能、卡各一格；格子多了整排等比缩小。

### 9.6 道具和花钱

| 关卡 | 道具 |
|---|---|
| 1–10 | 全部免费，每种每关最多 2 次 |
| 11–14 | 每关第一次免费，再用扣库存，没有就买 |
| 14 关过完 | 送小礼包：每种技能各 1 个，弹窗说「从下一关起道具要用库存或金币了」 |

- 每天第一次用技能免费照旧。
- **撤销**每关最多 3 次；太便宜规定路线就变成反复试错。
- 第 15 关是免费结束后的第一个难关，也是第一次要自己掏金币的地方；第 20 关守关是第二次。
- 金币数字（过关、首次三星、连击目标、礼包）等关卡按规定路线生成出来，用 `./run.sh eco-sim` 重算后再定。

### 9.7 测试用的难度调试页

开发版里「设置 → 难度调试」，用户自己调、自己试（用户 2026-11-19）。只在开发版出现、正式版自动不出，代码一直留着；页面是底座的通用模块，以后别的游戏照样用（用户 2026-11-19，`docs/10` 第 9 节）。内容超出屏幕就上下滚动：

- **整体三档**：简单 / 标准 / 困难 = 暂存槽 +1 / 照设计 / −1，连击窗口 2.5 / 2 / 1.5 秒，所有关立刻生效。
- **单关**：每关收紧时按「正常打法（随手点的玩家）能过几成」每 10% 存了一档（`config/levels_lab/`，`tools/level/route.ts --lab`），选一关、挑一档（每档写着正常打法能过几成、想清楚能过几成、按路线最多能连几下）顶替这一关、马上试玩；「恢复包里的」「进度到这关」「金币 +1000」「生命补满」；页面底下列出改过哪几关、各用哪一档，截图发给开发，写进难度曲线重新生成。选的档存在本机（第二版换了存的键，第一版按容错挑的档不再沿用）。
- **演示**（用户 2026-11-19 问「我怎么验证你这些正常打法能过的……万一它一定就不能过呢」）：「看路线（一定能过）」让电脑按关卡文件里存的参考解（想清楚的玩家赢下来的那条）一步步点，每步先给要点的鱼套金圈；打得完就证明这一档不用道具一定过得去，也能看清路线怎么走。「看正常打法打一局」现场按正常打法（随手点的玩家）打一局，每次走法不一样；输的局会在走错的那一步（点完以后不用道具就过不去了，求解器现算）套红圈、停一下，结束时报「第几步就走错了」。正常打法能过 16% 的档，大部分局是在第 13–15 步走错、紧接着输（2026-11-19 用户看到「直接输了」）。演示打的是在用的那一档，暂存槽和缸位照关卡原样（不吃整体三档），不记成绩、不扣命、不算连输，打完回调试页报结果。调试页换了档的关，自己试玩时也一直是这一档原样：不换连输后的简单变体，也不送连输 4 次的第 3 缸位。原来想在手机上按旋钮现场生成，实测一关要 1–7 分钟，改成挑现成的。
