# 01 玩法设计

## 1. 一句话

小鱼被困在层层叠叠的气泡里。点鱼，把它送进要这种鱼的鱼缸；一缸装满 3 条就送走，换下一缸。救出全部小鱼过关，过关得图鉴卡和星星，星星用来重建海湾。

目标用户：泛休闲玩家，单局 2–4 分钟，单手竖屏，零文字教学也能上手。

## 2. 局内界面构成

```
┌──────────────────────────┐
│ 关卡号   金币        设置 │  顶栏
│ [缸A 2/3][缸B 0/3][＋][＋]│  鱼缸架：4 个缸位，默认开 2 个
│   下一缸预告: 🐟          │  预告接下来 1 个缸要的鱼
│ 进度 37/123 [ ][ ][ ][ ][ ]│  救援进度 + 暂存槽 5 格
│                          │
│      气 泡 场（多层）      │  占屏幕 60%
│                          │
│  [渔网]  [吹泡]  [洗牌]   │  三个道具
└──────────────────────────┘
```

## 3. 核心规则

### 3.1 名词

| 名词 | 定义 |
|---|---|
| 气泡 | 场上的容器，内含 1–5 条鱼。有层级（layer），高层压低层 |
| 开放气泡 | 没有被任何更高层气泡压住的气泡。只有开放气泡里的鱼能点 |
| 鱼缸 | 顶部容器，有一个目标鱼种和容量（默认 3） |
| 订单队列 | 本关所有鱼缸目标的有序列表，关卡数据里写死 |
| 暂存槽 | 5 格。点了当前没有缸要的鱼，就进暂存槽 |

### 3.2 一次点击的结算顺序

1. 玩家点一条开放气泡里的鱼。
2. 若有激活的鱼缸目标是该鱼种且未满 → 鱼飞入该缸（多个缸都要时进最左边的）。
3. 否则 → 鱼进暂存槽最左空位。
4. 该气泡若已空 → 破裂，重新计算哪些气泡变为开放。
5. 任一鱼缸满 → 该缸游走，从订单队列取下一个目标补位（队列空则缸位空置）。
6. 新缸出现后，暂存槽里匹配的鱼自动按从左到右飞入。回到第 5 步，直到没有变化（连锁）。
7. 判定胜负。

动画期间允许继续点击（输入排队，逻辑立即结算、表现追帧），保证手感不卡。

### 3.3 胜负

- **胜**：场上与暂存槽都没有鱼。
- **负**，三种情况任一：
  - 结算完成后暂存槽仍是满的（或有鱼进不去暂存槽）；
  - 限时缸倒计时归零；
  - 场上还有鱼，但没有一条能点（全被锁链或冰封挡住）。
- 倒计时在弹窗、广告、切后台期间暂停。
- 失败后可看一次广告复活（每关限 1 次）：效果等同一次「吹泡」；因限时缸失败则 +30 秒；因无鱼可点失败则解开全部锁链与冰封。

### 3.4 可见信息（策略深度来源）

- 被压住的气泡半透明变暗，但里面的鱼看得见，玩家可以规划拆泡顺序。
- 鱼缸架下方预告下一个缸的目标鱼种。
- 开第 3、4 个缸位 = 同时接更多订单 = 降低难度，是主要的广告点。

### 3.5 鱼缸位

| 缸位 | 开启方式 |
|---|---|
| 1、2 | 默认开启 |
| 3 | 本关内看广告开启；第 1–10 关免费送作为教学；广告不可用时改为 60 金币 |
| 4 | 本关内看广告开启（需先开 3） |

开启只在本关有效。Google Play 版购买「去广告」后 3 号位永久开启。

## 4. 障碍机制

按关卡进度逐个引入，每个机制首次出现的关卡只用它一个，并配 1 步引导。

| 机制 | 解锁关 | 规则 |
|---|---|---|
| 多层气泡 | 3 | 基础机制，高层压低层 |
| 锁链泡 | 12 | 泡上有数字 N，每完成 1 个鱼缸 N−1，到 0 解锁。锁住时不能点，也不算遮挡解除 |
| 限时缸 | 25 | 该缸出现后开始倒计时（45–90 秒），归零失败 |
| 迷雾泡 | 40 | 被压住时鱼只显示剪影，开放后才显形 |
| 冰封泡 | 60 | 相邻（数据里指定邻居）任一气泡破裂后才解冻 |
| 大鱼缸 | 80 | 容量 6 的缸，占用一个订单位 |
| 结伴鱼 | 110 | 两条鱼系在一起，点一条两条一起走，按先后各自结算去向；第二条没地方去即失败 |

单关最多叠加 3 种障碍。

## 5. 道具

| 道具 | 效果 | 初始赠送 | 金币价 |
|---|---|---|---|
| 渔网 | 选一个激活的鱼缸，从场上任意位置（含被压住的）直接捞鱼把它补满 | 1 | 180 |
| 吹泡 | 把暂存槽里所有鱼吹成一个新气泡，放在气泡场上方的固定回流位，不压住任何气泡 | 1 | 120 |
| 洗牌 | 场上所有未救出鱼的种类重新分布（各种类数量不变）。不是纯随机：用关卡生成器按当前局面重新构造一个低难度的可解分布，所以洗牌一定是救场而不会洗死 | 1 | 100 |

道具数量为 0 时，按钮显示「＋」：金币够则金币买，不够则看广告得 1 个。每关每种道具最多用 2 次。

## 6. 外围系统

### 6.1 主界面与导航

底部 5 个页签：商店 · 家园 · **主页** · 排行 · 图鉴。主页一个大的「开始第 N 关」按钮，周围是签到、设置入口。

### 6.2 图鉴与鱼票

- 共 60 种海洋生物，5 档稀有度：普通 30 / 精良 15 / 稀有 8 / 史诗 5 / 传说 2。
- 关卡里出现哪些鱼由关卡段决定（越往后鱼池越大），与是否拥有卡片无关。图鉴记录的是「收藏」。
- **过关卡**：每过一关得 1 张。概率：普通 80% / 精良 17% / 稀有 3%。每 3 关至少 1 张未拥有的卡，直到普通和精良集齐。
- **鱼票**（第二种货币，只用于图鉴）：10 张鱼票开 1 个珍稀卡包，得 1 张卡。概率：精良 60% / 稀有 28% / 史诗 10% / 传说 2%。每 5 包至少 1 张未拥有的卡。

  | 鱼票来源 | 数量 |
  |---|---|
  | 挑战关过关 | 3 |
  | 签到第 3、6 天 | 5 |
  | 建完一个场景 | 10 |
  | 每日首胜 | 1（看广告双倍） |

  鱼票不出售。史诗和传说只能从珍稀卡包获得，所以鱼票是长期追求。
- 重复卡自动换金币：10 / 25 / 60 / 150 / 500。
- 集齐一档稀有度送头像框和金币。
- 两个卡包的概率在图鉴页公示。

鱼种名称与造型全部原创，清单见 `config/species.json`（按 `docs/03-美术规范.md` 第 4 节的规则命名）。

### 6.3 家园「重建海湾」

- 每过 1 关得 1 颗星（挑战关 2 颗）。
- 每个场景有 10 个建造步骤，每步花 1–3 颗星，点一下播一段建造动画。
- 建完一个场景开宝箱（金币 + 道具 + 10 张鱼票），解锁下一个场景。
- 建完的场景可以随时「回顾」：进入完整场景画面，点建筑重播建造动画。
- v1.0 做 4 个场景：珊瑚小镇、沉船集市、海藻森林、珍珠灯塔。约覆盖前 80 关。

### 6.4 七日签到

第 1–6 天：金币 50 / 道具 / 鱼票 5 / 金币 100 / 金币 200 / 鱼票 5；第 7 天宝箱（金币 + 3 种道具各 1）。可看广告双倍。断签不清零，按累计天数领，7 天一轮循环。

### 6.5 排行榜

按「本周过关数」排名，周一 0 点重置。**全球榜、本地榜不做**（需要服务器）。v1.0 只接各平台自带的榜：微信好友榜、抖音平台榜、Google Play 的 Play Games 榜；开发阶段用写死的假数据填充界面。

### 6.6 头像与昵称

通过平台接口获取（微信、抖音的用户信息授权，Google Play 的 Play Games 资料），显示在主页左上角和排行榜自己那一行。玩家拒绝授权时用默认头像和随机昵称。**开发阶段写死**一组头像昵称，由 `debug` 平台实现返回。

### 6.7 体力

v1.0 **不设体力**。广告变现的小游戏靠局数吃饭，体力会直接砍收入。

## 7. 经济

两种货币：**金币**用于道具，**鱼票**只用于图鉴的珍稀卡包（见 6.2）。

| 来源 | 数量 |
|---|---|
| 过关 | 20，挑战关 40 |
| 过关看广告双倍 | ×2 |
| 签到 / 场景宝箱 / 重复卡 | 见上 |

| 去向 | 数量 |
|---|---|
| 买道具 | 100–180 |

基准：不看广告的玩家每 6–8 关攒够 1 个道具；数值全部在 `economy.json`，上线后按数据调。

## 8. 变现

### 8.1 广告位清单

| 编号 | 类型 | 位置 | 奖励或规则 |
|---|---|---|---|
| `rv_double_coin` | 激励视频 | 过关结算「双倍领取」 | 过关金币 ×2 |
| `rv_bowl_slot` | 激励视频 | 局内带加号的缸位 | 本关开启第 3 / 4 缸位 |
| `rv_revive` | 激励视频 | 失败弹窗 | 复活，每关 1 次 |
| `rv_tool` | 激励视频 | 道具为 0 且金币不足 | 得 1 个该道具 |
| `rv_signin_double` | 激励视频 | 签到弹窗 | 当日奖励 ×2 |
| `rv_first_win_ticket` | 激励视频 | 每日首胜 | 鱼票 ×2 |
| `rv_free_coin` | 激励视频 | 商店「免费金币」 | 50 金币，每日 5 次 |
| `int_level_end` | 插屏 | 过关结算关闭后 | 第 8 关之后；间隔 ≥ 90 秒且至少隔 2 关；刚看完激励视频则跳过 |
| `bn_result` | Banner | 结算、暂停弹窗底部 | 局内操作区和主页不放 |

规则：

- 激励视频必须完整看完才发奖；中途关闭不发奖也不扣次数。
- 广告不可用时：有金币替代价的改为金币支付（缸位 60），其余入口隐藏，不能让玩家点了没反应。
- 所有频控数值在 `config/ads.json`。

### 8.2 开发阶段：模拟广告与广告测试页

现在没有真实广告接口，先用模拟实现把整条链路做完：

- **模拟广告页**（`debug` 平台）：
  - 激励视频：全屏页，显示广告位编号、5 秒倒计时；「看完」「中途关闭」「加载失败」三个按钮，分别对应三种真实结果。
  - 插屏：全屏页，1 秒后出现关闭按钮。
  - Banner：底部一条占位色块，标着广告位编号。
- **广告测试页**（设置里的入口，仅调试构建可见）：列出上表全部广告位，每个可单独触发；显示今日各广告位的展示次数、频控状态，可一键重置频控，可全局切换「广告可用 / 不可用」来检查降级表现。

接入真实平台时只替换 `src/platform/` 里的实现，业务代码和广告位编号不变。

### 8.3 内购（仅 Google Play）

去广告（关闭插屏和 Banner，永久开启第 3 缸位；激励视频保留）· 金币包 3 档 · 新手礼包。国内小游戏不上内购，鱼票任何平台都不出售。

### 8.4 商店页内容

每日免费金币（看广告）· 道具金币价购买 · Google Play 版的内购商品。

### 8.5 留存钩子

图鉴保底、场景宝箱进度条、签到；小游戏端接「添加到桌面 / 侧边栏复访」奖励与分享求助（分享得 1 个道具，每日 3 次）。

## 9. 新手引导

| 关 | 教什么 | 方式 |
|---|---|---|
| 1 | 点鱼进缸 | 手指指向唯一可点的目标鱼，3 种鱼 9 条，不可能失败 |
| 2 | 暂存槽 | 故意让第一步只有非目标鱼可点 |
| 3 | 气泡遮挡 | 高亮被压住的泡 |
| 5 | 道具 | 强制用一次吹泡 |
| 各机制首关 | 新障碍 | 1 步手指引导 |

引导只用手指和高亮，不用大段文字。
