# 01 玩法设计

## 0. 设计原则（先读这一节）

1. **收入靠广告，新用户靠分享。** 所有系统都围绕两件事设计：让玩家习惯看激励视频、习惯分享。
2. **金币要花得掉。** 金币只有一种，来得快、去得也快：买生命、买技能、抽奖、开缸位。金币花完，玩家才会去看广告。
3. **退出有代价。** 中途退出、重试、失败都扣生命，逼玩家在卡住时用技能、看广告复活，而不是无成本重开。
4. **爽。** 每一次点击、入缸、满缸、连击、结算都要有声音、有动画、有数字跳动。动画不挡操作。
5. **好找。** 同一关里的生物一眼能分清（颜色和轮廓都不同）。
6. **文字摆正。** 汉字和单词不倾斜、不旋转、不用斜体；数字允许轻微倾斜。

一句话：海洋生物被困在气泡里。点它，送进要它的鱼缸；一缸收满 3 只，鱼缸连同里面的生物一起消失，换下一缸。全部救出过关。

目标用户：泛休闲玩家，单局 2–4 分钟，单手竖屏，零文字教学也能上手。

## 1. 局内界面

```
┌──────────────────────────┐
│ (🐟 6/63)        (第 3 关)│  左：已救/总数   右：关卡号。局内不显示金币
│ [缸] [缸] [＋] [＋]       │  木架上 4 个缸位，默认开 2 个，未开的是暗缸加绿色「＋」
│ ▤▤▤  ▤▤                   │  每个缸前面叠着订单卡：一张卡一条要的鱼，进一条揭一张；空缸里不画鱼
│      [ ][ ][ ][ ][ ]      │  暂存槽 5 格，居中、低调；只剩 1 格时那一格红框闪
│                          │
│        气 泡 场           │  占屏幕 60%，掉落关里气泡从上方落下
│                          │
│ [技能][技能][技能][技能] ⚙│  技能键 + 设置；未解锁的显示灰锁和「第 N 关」
```

- 「第 N 关」在挑战关显示为金色。
- 金币只出现在弹窗里（开缸位、买技能、买生命）和结算页。
- 所有弹窗共用一套样式，见 `docs/03` 的「弹窗」。

## 2. 核心规则

### 2.1 名词

| 名词 | 定义 |
|---|---|
| 生物 | 鱼、海星、螃蟹、鲨鱼等，规则上完全等价，下文统称「鱼」 |
| 气泡 | 场上的容器，内含 1–5 条鱼 |
| 可点气泡 | 已在场上、没被更高层气泡压住、没被锁链或冰封挡住的气泡。只有可点气泡里的鱼能点 |
| 鱼缸 | 顶部容器，带一张订单：目标鱼种和容量（默认 3） |
| 订单队列 | 本关所有订单的有序列表，关卡数据里写死 |
| 暂存槽 | 5 格。点了当前没有缸要的鱼，就进暂存槽 |
| 回流位 | 吹泡把暂存槽的鱼吹回来后停靠的一排小气泡，在气泡场下沿，可直接点，不压住也不被压住 |
| 候场队列 | 掉落关里还没落到场上的气泡，玩家看不到 |

### 2.2 一次点击的结算顺序

1. 玩家点一条可点气泡里的鱼（点的是鱼，不是整个气泡）。
2. 若有激活的鱼缸要这种鱼且未满 → 鱼飞入该缸（多个缸都要时进最左边的）。
3. 否则 → 鱼进暂存槽最左空位。
4. 该气泡若已空 → 破裂，重新计算可点气泡；掉落关里从候场队列补落新气泡（见 2.5）。
5. 任一鱼缸满 → 该缸连同里面的鱼消失，从订单队列取下一张订单补位（队列空则缸位空置）。
6. 新缸出现后，暂存槽里匹配的鱼自动按从左到右飞入。回到第 5 步，直到没有变化（连锁）。
7. 判定胜负。

动画期间允许继续点击（逻辑立即结算、表现追帧），保证手感不卡。

### 2.3 胜负

- **胜**：场上、候场队列、暂存槽、回流位都没有鱼。
- **负**，三种情况任一：
  - 结算完成后暂存槽仍是满的；
  - 限时缸倒计时归零；
  - 还有鱼，但回流位是空的，且场上没有一条能点。
- 倒计时在弹窗、广告、切后台期间暂停。
- 失败时先弹**复活弹窗**（每关 1 次，看广告）：效果等同一次「吹泡」；因限时缸失败则 +30 秒；因无鱼可点则解开全部锁链与冰封。放弃复活才算失败，扣 1 条生命（见 5.1）。

### 2.4 鱼缸位

| 缸位 | 开启方式 |
|---|---|
| 1、2 | 默认开启 |
| 3、4 | 点「＋」弹窗：650 金币，或看广告。先开 3 再开 4 |

开启只在本关有效。多开一个缸 = 同时接更多订单 = 明显变简单，是主要的广告点和金币去向。

但**开缸不等于过关**：关卡按「第 3 缸让胜率明显上升、但后期仍可能失败」生成（目标见 `docs/02` 第 2.1 节）。这样第 4 缸也有用，技能和复活也还有用武之地；如果开一个缸就稳过，玩家卡关时只会点这一个按钮，其它广告点和金币去处都没人用。

### 2.5 掉落

- **第 1–25 关**：气泡一次摆完，一层压一层，被压住的看得见但点不了。
- **第 26 关起**：掉落关。关卡有一个「场上容量」，开局落下容量个气泡，其余在候场队列里看不见；每破一个气泡，队列里的下一个从屏幕上方落下。左上角总数包含候场的鱼，所以玩家知道还有多少，但不知道是什么。
- **挑战关**：场上容量更小、候场更多，未知更多。
- 落点只是表现：逻辑上候场队列是有序的、确定的，位置由界面层摆放，不影响规则与可解性。
- 掉落关不再用「高层压低层」，未知信息全部来自候场队列。

### 2.6 自动收尾与提示

- **自动收尾**：剩下的鱼（含候场）只有一个种类时，不用玩家再点，气泡每 0.2 秒自动破一个，鱼自动入缸（仍计连击），随后进过关演出。
- **提示**：玩家发呆 7 秒（前 3 关 2 秒），在一条点了能直接进缸的鱼上套呼吸光圈。不指向没显形的迷雾鱼。

## 3. 爽感：动画、连击、结算

这一节是验收标准。交付时按时间点连续截图自检并给用户看；声音靠用户反馈。

### 3.1 基础动画（每一步都要有）

| 时机 | 表现 |
|---|---|
| 开局 | 载入页淡出。没有遮挡的关卡：气泡从场地上沿一个接一个落下来，落在地上或别的气泡上、压扁一下弹回，堆成一堆。有遮挡的关卡：气泡按关卡摆法依次弹出，再由重力压实 |
| 点鱼 | 鱼原地一弹（放大再回落），点击处一圈水波，短促「啵」声 |
| 鱼飞进缸 | 沿弧线飞约 0.4 秒，身后拖一条蓝白闪光尾迹；多条鱼依次出发 |
| 入缸 | 缸口溅起一把小气泡和一圈扁的涟漪，鱼缸轻轻一弹，缸里的目标鱼和数量牌跳一下；清脆的一声加水花声（每次音高略有不同） |
| 鱼进暂存槽 | 短弧线落入，槽格轻弹，声音比入缸低沉 |
| 气泡破裂 | 碎成几粒小泡沫向外散开 |
| 满缸 | 订单卡打勾 → 三条鱼在缸里抖动约 0.5 秒 → 鱼缸发白光膨胀 → 炸成光点，整排木架扫过一道亮光 → 新缸和新订单卡从上方落下。全程约 1.5 秒 |
| 满缸夸奖 | 缸旁跳出「不错！」「真棒！」「太强了！」，摆正，带描边和弹跳 |
| 暂存槽告警 | 只剩 1 格时该格红框闪动，伴随低频提示音 |
| 新气泡落下 | 从场地上沿落下来（落点在刚破的气泡上方附近），掉在堆上，沿着别的气泡滚到位，落地压扁一下、轻轻「咚」一声 |
| 气泡破了之后 | 压在上面的气泡受重力落下来、滚进空出来的位置 |
| 常驻 | 气泡的泡膜像果冻一样慢慢鼓一下、扁一下，彩虹边沿着泡边流动，隔一两秒某个气泡的高光闪一颗小星（被压住的不带流光）；背景里一直有小气泡从下往上冒、左右摆着；每个鱼缸里也有小气泡从缸底冒到水面（用户 2026-11-16） |
| 弹窗 | 缩放回弹着出现，背景压暗 |

**气泡的重力**（用户 2026-11-16 定）：场上所有气泡都受重力，像一堆有分量的球——上面的压着下面的，下面的破了上面的就落下来，落在别的气泡上会沿着它滚下去，不会穿过别的气泡直接到底。这只是画面：谁压着谁（遮挡）仍然由关卡数据决定，不看画面位置。所以有遮挡的关卡里，互相压着的一对之间连一条「弹性带」：两个圆心的距离只能在设计距离的 60%–100% 之间，压着的始终压着，画面上的遮挡和规则一致；但这一对能转、能挪，整堆会滚进空当里压实（用户 2026-11-16：原来整组焊死成一块，堆里留着空）。其中一个破了，连着它的带就没了，上面的落下来。开局前先在内存里试算一遍，把气泡整体放大或缩小到「压实后刚好堆满场地」（半径上限 150），所以不管这关气泡多少，场地上面都不会空着一大截。鱼缸坐在木架上（缸底压着木架上沿），数量牌贴在木架正面。

### 3.2 连击

- **规则**：点到的鱼直接进缸算一次命中；2 秒内再次命中连击 +1；鱼进了暂存槽或超时清零。暂存槽里的鱼自动补进新缸也算命中。
- **档位与金币**（数值在 `economy.json` 的 `combo`）：

  | 连击数 | 档位 | 主色 | 每次命中金币 |
  |---|---|---|---|
  | 4–6 | 不错 | 蓝 | 1 |
  | 7–9 | 漂亮 | 金 | 2 |
  | 10–14 | 太强了 | 红 | 3 |
  | 15+ | 无敌 | 紫 | 5 |

  4 连开始算连击（用户 2026-11-16 定：先是 6 连太难触发，改成 3 连后又太容易，随便点三下装满一缸就出，所以定在 4——要连到下一缸才算）。比最初起算早、命中次数多，每次的金币相应调低，每关上限不变。

  每关连击金币上限 60。连击的回报主要是爽感和送卡，金币只是点缀：过一关的金币主要来自过关本身（见第 6 节）。
- **位置**（用户 2026-11-16 定）：不带底板的大号「连击 ×N」艺术字，浮在暂存槽那一排的正中，**没有倒计时条**（用户 2026-11-16 定：不要底板、不要进度条）；连击金币每涨一次从它右边飘一个「金币 +N」；断连后抖一下往下掉、淡出。顶栏不变（进度、关卡号、设置都一直在）。不在场地中间常驻大数字，不挡气泡（用户 2026-11-15 定）。
- **连击送收藏卡**：连击数第一次到 10 / 15 / 20 时各掷一次，30% / 60% / 100% 送 1 张收藏卡，每关最多 1 张。当场飞出提示，不打断操作，结算时列出。收藏开放（第 6 关）前连击不送卡。
- **最高连击奖**：本关最高连击 ≥ 6（不跟着起算数降，3–5 连不给），结算额外给「最高连击 × 2」金币，上限 40。
- **表现**：连击要爽，让人觉得整个屏幕都在跟着动，画面、声音、震动一起升级（用户 2026-11-16 定）。同一天又定了一条底线：**不盖鱼缸和目标卡、不盖气泡、不影响操作**——所以鱼缸上炸的光、四边光框、升档时的闪光、放射光、冲击波、彩纸、烟花、往上冒的光点，全都垫在玩法后面那一层（气泡、鱼缸、目标卡画在它上面），动效本身不变。「连击」、数字和四档夸奖词都是 Codex 画的艺术字（中文用图，其它语言用字）。
  - **蓄势（第 2、3 击）**：连击计的位置冒小号的「×2」「×3」；轻震一下。
  - **每次命中（4 连以上）**：连击计的数字从 2 倍砸下回弹（可轻微倾斜），连击字整块顿一下；鱼缸背后炸一圈档位色的柔光、光环和火花；整个场面瞬间放大一点再弹回；四边光框闪到最亮；轻震一下。
  - **常驻（4 连以上）**：屏幕四边按档位色发光呼吸；玩法后面垫一层整屏的放射光慢慢转；光点和小气泡从屏幕底下往上冒（都垫在玩法后面）。档位越高越亮、转得越快、冒得越密。
  - **升档**：夸奖艺术字（宽不到屏幕的四成，落在暂存槽那一排，不伸到上面的鱼缸、目标卡和下面的气泡上，用户 2026-11-16 定）从大砸下（背后档位色柔光和慢慢转的爆炸星，**不用飘带**，用户 2026-11-16 定）。落地的一刻：全屏闪档位色、放射光炸开到整屏、两圈冲击波、屏幕震、全场气泡从夸奖词往外鼓一圈、鱼缸依次跳一下、两个下角往中间喷彩纸；红档和紫档再在场地里炸 3 / 5 发烟花。约 1 秒后夸奖词缩小飞进连击计。蓝、金档中震，红、紫档重震。
  - **声音**：每条鱼进缸都有进缸声（清脆一声 + 水花）；连击起算（第 4 击）后每一击再叠一声「叮」（低频鼓点 + 铃音），沿五声音阶一击升一个音，共 11 级，到顶后停在最高音。升档音分四档：竖琴往上滑 → 颤音琴和钢片琴的和弦 → 钟琴点几个亮音；档位越高和弦越高，依次加小镲、铜管和吊镲、定音鼓和小号。断连是两个往下走的低音。
  - **断连**：数字变灰，连击计抖一下往下掉并淡出；光框、放射光、光点一起收掉。
  - 震动在设置里能关；音效和震动的强弱都跟着档位走，不单独配置。

### 3.3 过关结算

- 最后一缸消失后停半拍 → 闪白、放射光炸开、屏幕震、两个下角喷彩纸、四发烟花约 1 秒（重震一下）→ **只出一个结算页**，同屏完成，不分段。
- 结算页：横幅从大砸下，落地时屏幕震、金色放射光炸开、两个下角往上喷彩纸铺满全屏 → 宝箱原地弹出 → 三颗金星从宝箱转着飞上去依次落位（灰色星位先在；三颗星三个音 do、mi、sol，每颗落位轻震）→ 宝箱越晃越大、白光一闪弹开（放射光、冲击波、重震），光芒放大，两条鱼跳一下 → 奖励条从下面滑上来，金币从星星处飞进金币图标，数字滚动（过关 + 连击 + 最高连击奖），滚完弹一下 → 按钮从下往上依次升起，「下一关」呼吸。播完后星星周围隔一会闪一颗星光。
- 从过关到可以点「下一关」不超过 3 秒，任何时候点一下可跳过动画直接到最终状态。
- 开出收藏卡时：稀有度越高越华丽，史诗和传说全屏闪光。
- **排版要少字少按钮**（用户 2026-11-15 定）：奖励只有一排「图标 + 数字」（金币总数、技能、收藏卡、首胜奖励），不写明细说明。按钮只有一排：「金币 ×2」（广告）和「下一关」；回主页是左上角的小图标按钮，开出稀有以上的卡时右上角多一个「分享」。不再有「再开一个宝箱」。

### 3.4 过关宝箱

| 关卡 | 安慰金币 30–80 | 技能 1 个 | 收藏卡 1 张 |
|---|---|---|---|
| 普通关 | 35% | 12% | 53% |
| 挑战关 | — | — | 100%，稀有以上概率翻倍 |

收藏卡稀有度：普通 70% / 精良 22% / 稀有 6% / 史诗 1.8% / 传说 0.2%。连续 4 关没出卡，第 5 关必出一张未拥有的卡。过关基础金币：普通关 100，挑战关 200。

收藏开放（第 6 关）前宝箱不出卡：该出卡时改发安慰金币 30–80，挑战关也一样。

## 4. 障碍机制

按关卡进度逐个引入，每个机制首次出现的关卡只用它一个，并配 1 步引导和一句说明。**解锁关一律是挑战关的下一关**（周期里最容易的一关），先学会、再到后面的挑战关里考；一关只首发一样新东西（2026-11-16 定，原因见 `docs/02` 第 2.2 节）。

| 机制 | 解锁关 | 规则 |
|---|---|---|
| 多层气泡 | 3 | 高层压低层，第 3–25 关使用 |
| 锁链泡 | 16 | 泡上有数字 N，每完成 1 个鱼缸 N−1，到 0 解锁 |
| 掉落 | 26 | 见 2.5 |
| 限时缸 | 31 | 该缸出现后开始倒计时（45–90 秒），归零失败 |
| 迷雾泡 | 41 | 泡上蒙一团雾，里面每条鱼都显示成同样的问号，看不出种类（数量看得出）。迷雾泡在场后，每破一个别的气泡雾就淡一层，泡下沿那排小泡泡也破一个（一个小泡泡代表还要破一个别的气泡；用户 2026-11-16：数字角标看不懂），破完显形。没显形时也能点，点到的是哪条鱼要点了才知道 |
| 冰封泡 | 61 | 被冰冻住的泡点不了，冰晶连线连着 1–2 个旁边的气泡，其中任一个破了就解冻 |
| 大鱼缸 | 81 | 容量 6 的缸 |
| 结伴鱼 | 111 | 两条鱼系在一起，点一条两条一起走，按先后各自结算，每条都和普通的鱼一样：有缸要就进缸，否则进暂存槽。第一条把暂存槽占满、第二条没地方放时失败（和普通的鱼把暂存槽塞满一样） |

- **迷雾为什么不用剪影**：同一关里生物的轮廓各不相同（`docs/03` 第 4.1 节），剪影一眼就能认出是什么，迷雾就白设了。
- **冰封为什么要画连线**：第 26 关起是掉落关，后落下的气泡位置由界面摆放，「旁边」不是逻辑上的关系。界面把冰封泡摆在它依赖的气泡旁边，并画出连线，玩家才知道该先破哪个。
- 单关最多叠加 3 种障碍；障碍种数每 5 关一个强弱节奏，新机制解锁后先密后疏，不会几十关都是同一套（`docs/02` 第 2.4 节）。

## 5. 外围系统

### 5.0 海域：所有内容按海域分

游戏世界是一片海湾，分成 **6 个海域**。收藏的册子、关卡的背景、选关页用这同一套海域，不再各分各的。**每 20 关一个海域**（用户 2026-11-17 定：关卡和收藏对起来）：打到一片新海域的第一关，局内背景换成这片海域的，收藏里这片海域的册子同时开放，选关页也多出这一页。

|---|---|---|---|---|---|

| 2 | 珊瑚花园 | `coral` | 珊瑚礁，颜色最鲜艳的一片 | 21 | 第 21–40 关 |

**为什么按海域分，不按生物类别分**：按类别（鱼、虾蟹、贝类）分，一册里全是长得差不多的东西，收集没有新鲜感，也和进度挂不上钩。按海域分，每到一片新海域就换一批各式各样的生物，背景、收藏同时换新。

**生物不做「同一种换颜色」**：60 种生物每种都是独立的造型和名字。等级就是稀有度（普通 30 / 精良 15 / 稀有 8 / 史诗 5 / 传说 2），越稀有的是越特别的生物，不是同一种的高级版。局内尤其不能出现同形状不同颜色的生物（不好找，见第 0 节「好找」）。以后要加内容，可以给已有生物出「闪光版」作为额外收集目标，不占这 60 张。

### 5.1 生命

| 项 | 设定 |
|---|---|
| 上限 | 5 条 |
| 恢复 | 每 20 分钟 1 条，满了停止计时 |
| 扣 1 条 | 失败后放弃复活；中途回主页；中途点重试 |
| 不扣 | 过关；一步没动就退出；第 1–5 关 |
| 重玩旧关 | 同样规则 |

- **生命为 0** 点开始时弹「生命」弹窗，四条路：
  1. 看广告得 1 条（`rv_life`），每天 5 次。这是主按钮。
  2. 400 金币买 1 条；1500 金币补满 5 条。
  3. 分享得 1 条，每天 3 次。
  4. 等：显示「下一条 12:35」倒计时。
- **命要值钱**：一条命的金币价（400）大约是打两关的收入，所以失败、中途退出是真的有代价，玩家才会用技能、看广告复活，而不是无成本重开（第 0 节原则 3）。
- **无限生命**：作为奖品，期间不扣命，顶栏心形显示「∞」和剩余时间。来源：每日首胜 10 分钟、抽奖 15 分钟、签到第 7 天 30 分钟。
- **离开确认**：已经走过步时点回主页或重试，弹「现在离开会失去 1 条生命」，主按钮「继续玩」，次按钮「离开」。
- **防刷**：无服务器，按本地时间算；检测到时间倒退则这段不恢复，其余接受。

### 5.2 技能

| 技能 | 效果 | 解锁关 | 金币价 |
|---|---|---|---|
| 洗牌 | 场上未救出的鱼重新分布（各种类数量不变），由生成器按当前局面重排成更易的可解分布，一定是救场。结伴鱼不拆开，两条一起换到同一个气泡里 | 4 | 500 |
| 吹泡 | 把暂存槽里所有鱼吹到「回流位」，腾空暂存槽；回流位的鱼随时可点 | 7 | 600 |
| 渔网 | 选一个激活的鱼缸，直接捞鱼把它补满，每条都算连击。顺序：回流位 → 开放的气泡 → 场上其它气泡 → 候场 | 9 | 900 |
| 洋流 | 场上和回流位里能直接进缸的鱼依次自动入缸（约 0.13 秒一条），每条都算连击；**只装用的那一刻架上的缸**，这几个缸装满后换上来的新缸不管（用户 2026-11-16 试玩：原来新缸上来接着进，掉落关里几乎所有的鱼都点得到，用一次就清完整关）；不会把鱼送进暂存槽；结伴鱼两条都有去处才放行 | 12 | 1200 |

没显形的迷雾鱼，渔网和洋流照常能捞（技能知道是什么鱼），洗牌后迷雾计数不变。

养成使用习惯的手段：

- 解锁当关送 2 个，并强制教学用一次。
- 每种技能每天第一次免费。
- 暂存槽只剩 2 格时，能救场的技能键发光跳动。
- 每关每种最多用 2 次。
- 数量为 0 时按钮显示「＋」：金币买，金币不够则看广告得 1 个。当前没有效果的技能（暂存槽空时吹泡、没有能进缸的鱼时洋流）不扣数量，局内给一句提示。
- 角标数量最多显示 99。
- 演出：渔网从技能键甩出大网扣向鱼缸；吹泡是一串小泡从技能键飘向回流位；洗牌是场地中央漩涡、气泡转一圈；洋流是一道水流横扫全场，鱼排队冲进鱼缸。

- 重复卡自动换金币：50 / 125 / 300 / 750 / 2500。
- 收集到的生物可以设为头像。
- **页面**：首页是总进度条（右端是终极大奖宝箱）和册子列表；没开放的册子是灰的，写「第 N 关解锁」；集齐未领的册子上有「领取」按钮，主页的收藏入口亮红点。点一册进去看 10 张卡和这一册的大奖。

- 册子、开放关、奖励都在 `client/assets/resources/config/economy.json` 的 `album`。

### 5.5 抽奖

宝箱抽奖页（原转盘，用户 2026-11-15 改），是金币的主要去向。页面是一只紫色宝箱（和主页入口图标同一只）、剩余次数和开箱按钮，**不展示概率表**，也不显示顶栏。宝箱周围飘着五个装着奖品的气泡（金币、收藏卡、无限生命、两种技能），只告诉玩家能开出什么。开箱动画约 1.6 秒：气泡被吸进宝箱 → 跟着一串越来越快、越来越高的音，宝箱一下一下鼓起来、越晃越大，背后的光越来越亮（每拍轻震）→ 弹开：闪白、放射光炸开、冲击波、彩纸、屏幕震、重震 → 奖品从箱口升起来亮相（十连是十个奖品喷出来排成两排）→ 收藏卡先翻面 → 弹出开奖。奖品、概率、次数规则不变，概率只在 `economy.json` 里配置。

| 次数来源 | 数量 |
|---|---|
| 每天免费 | 1 |
| 每日首胜 | +1 |
| 分享 | +1（每天 1 次） |
| 看广告 | +1（每天最多 3 次） |
| 金币 | 1000 一次，不限；十连 9000 |

| 奖品 | 概率 |
|---|---|
| 金币 200 / 500 / 2000 | 28% / 14% / 3% |
| 技能 1 个 | 15% |
| 无限生命 15 分钟 | 3% |
| 收藏卡 普通 / 精良 / 稀有 / 史诗 / 传说 | 20% / 11% / 4.5% / 1.3% / 0.2% |

十连保底 1 张稀有以上；连续 30 次没出史诗以上，下一次必出。概率不在页面上展示。若上架平台审核要求公示，再放到设置页里，不放回抽奖页。

### 5.7 选关与重玩

主页「开始」旁边的「选关」键打开选关页：**一页就是一个海域**（20 关，4 列 × 5 行的格子），标题牌写海域名，背景是这片海域的局内背景，左右两个键或横着划翻页就是换海域，打开时停在当前关那一页（用户 2026-11-16：原来是一条从下往上的长路线，关卡多了不好翻）。已通过的蓝色带绿勾、可重玩，当前关绿色带「当前」，后面的灰色上锁，挑战关紫色并插一面小旗。重玩每天前 5 次给金币和宝箱，之后不给奖；生命规则不变。重玩过关后点「下一关」进的是**刚打那一关的下一关**（从第 12 关重玩，下一关就是第 13 关），一路打到当前进度为止，不直接跳回最高那一关（用户 2026-11-16 定）。

**第 120 关之后**：关卡只有 120 个，第 121 关起只在后半段（第 61–120 关）里循环：第 121 关用第 61 关，第 180 关用第 120 关，第 181 关又回到第 61 关。后半段 60 关是挑战关间隔 5 的整数倍，所以挑战关仍然是每 5 关一个、位置对齐；不会回到前面的教学关。规则是 `Meta.level_file`。

### 5.9 任务中心、头像、昵称

**任务中心**代替原来的排行页（用户 2026-11-16 定），第 11 关开放；先是底栏第五个页签，同一天去掉底栏后是主页右列的入口（见 5.3）。原来排行页上的「每周过关目标 10 / 25 / 50 关」取消，奖励并入任务中心。

**为什么换**：没有自己的服务器，好友的分数只能交给平台的好友榜去显示（微信是一块独立的画布），游戏读不到名次，没法按名次发奖；新玩家没有好友在玩时榜是空的，白占一个页签。任务本地就能算，人人每天都有事做，还能把玩家往看广告、分享、抽奖上引（第 0 节原则 1）。

- **积分不是货币**：做完任务得积分，积分只用来推进度条、到档开宝箱，不能买东西。金币仍然是唯一的货币。
- **每日任务**：每天 6 项——3 项固定，另外 3 项从其余 6 项里按日期抽（只抽已开放功能的；同一天同进度的玩家抽到的一样）。做完一项自动记积分，不用点领取；没做完的一行有「前往」按钮，直接去能做它的地方。本地时间 0 点换一批，进度清零。

  | 任务 | 积分 | 怎么算 |
  |---|---|---|
  | 过 3 关（固定） | 30 | 重玩旧关、每日挑战过关也算 |
  | 救 30 只小鱼（固定） | 20 | 按每局已经救下的数量累计，输了、中途离开的那一局也算 |
  | 看 1 次广告（固定） | 20 | 任何一个激励视频看完都算 |
  | 打出 6 连击 | 20 | 单局最高连击到 6；输了的那一局也算 |
  | 用 1 次技能 | 20 | 每天免费的那一次也算 |
  | 完成每日挑战 | 20 | 第 20 关起才会抽到 |
  | 开 1 次抽奖宝箱 | 20 | 十连算 1 次 |
  | 分享 1 次 | 20 | 在任务页点「前往」直接分享；平台不支持分享时不进池子 |

  池子里共 8 项，每天 6 项（3 项固定 + 3 项随机）；一天能拿到的积分共 130，**每日积分封顶 100**，所以看广告、分享这类任务可以不做，但做了最省事。卡关的玩家靠救鱼、连击、用技能、看广告、抽奖也能拿到大半，不会因为过不了关一分没有。
- **每日宝箱**：今日积分到 20 / 50 / 80 / 100 各开一个。

  | 今日积分 | 奖励 |
  |---|---|
  | 20 | 80 金币 |
  | 50 | 随机技能 1 个 |
  | 80 | 120 金币 |
  | 100 | 收藏卡 1 张（普通 75% / 精良 25%，不保新） |

- **本周宝箱**：每日积分同时累计成本周积分，一周最多 700，周一 0 点清零。到 150 / 350 / 550 各开一个；550 的门槛意味着一周缺一两天也能拿满。

  | 本周积分 | 奖励 |
  |---|---|
  | 150 | 300 金币 + 随机技能 1 个 |
  | 350 | 收藏卡 1 张（精良以上，按过关宝箱的概率） |
  | 550 | 400 金币 + 每种技能 1 个 + 30 分钟无限生命 + 收藏卡 1 张（稀有以上，优先没有的） |

- **宝箱要自己点开**：到档的宝箱晃动、带红点，主页的任务入口亮红点；点没到的宝箱看里面有什么。每日的过了 0 点、本周的过了周一 0 点，没领的作废。任务开放（第 11 关）前照样记进度，但不能领。
- **金币不多发**：每日 200 × 7 + 每周 700 = 2100，和原来每周过关目标的 300 + 600 + 1200 相等，第 6 节的收支不变；多出来的只有重复卡换的金币。
- **卡不发太好**：每日挑战已经每天给一张优先没有的卡，所以每日任务的卡只出普通和精良、不保新；稀有以上只在本周宝箱；传说仍然主要靠过关宝箱和抽奖，抽奖这个金币去处不贬值。只出已开放册子里的卡，重复卡照常自动换金币。
- 数值都在 `economy.json` 的 `tasks`；规则是 `core/meta/tasks.ts`。
- **好友周榜先隐藏**（用户 2026-11-16）：按「本周首次通过的关卡数」排的好友周榜（平台能力）代码保留——`core/meta/weeklyRank.ts`、`pages/rank.ts`、平台接口 `getRankList`，本周过关数照常记在存档里——但游戏里没有任何入口，等接平台好友榜时再放进任务中心。不做自建全球榜，不按名次发奖。
- 头像昵称通过平台接口取，拒绝授权时用默认头像和随机昵称；也可以换成收藏里收集到的生物。
- 个人资料页：头像、昵称、当前关、最高连击、收藏进度。

### 5.10 暂停与设置

暂停弹窗：音乐、音效、震动三个开关，「回主页」「重试」（都会触发离开确认）。设置弹窗另有语言切换，默认中文。

### 5.11 每日挑战（第 20 关开放）

- 每天一关：从玩家已经打到过的挑战关里（取较难的后一半）按日期轮换，同进度的玩家同一天是同一关。用的是已经过校验的关卡，不现场生成；生物换一批，和当初打这一关时不一样。
- 每天免费进 1 次。**不扣生命、不算进度、不记连败**。免费的这一次在局内走了第一步才记次数，进来不走直接退出或重开不算。失败或走过之后中途重开，再试：看广告（`rv_daily_retry`）或花 300 金币。

- 过关开「每日宝箱」：300 金币 + 随机技能 1 个 + 一张收藏卡（优先给没有的）。本关的连击金币一起入账，在开奖弹窗里单列一项。一天只领一次。
- 连续 7 天过关再开「七日大宝箱」：1500 金币 + 每种技能 1 个 + 1 小时无限生命，开完从头数。中间断一天清零。
- 页面：宝箱大图、连续 7 天的进度格、每日宝箱里有什么、底部按钮（开始挑战 / 再试一次 / 今日已完成）。
- 数值在 `client/assets/resources/config/economy.json` 的 `dailyChallenge`。

### 5.12 家园「重建海湾」（已删除）

## 6. 经济

只有**金币**一种货币。**设计目标：玩家每天都差一点金币。** 收入靠广告，玩家看广告的理由就是缺金币、缺生命；金币发多了，广告就没人看。下面的数字是按这个目标算出来的设计值，还没经过真人试玩，上线前要拿实际数据再调。

### 6.1 收入

| 来源 | 数量 | 备注 |
|---|---|---|
| 过关 | 100，挑战关 200 | 主要来源 |
| 连击 | 每关最多 60，另有最高连击奖最多 40 | 点缀 |
| 结算看广告翻倍 | 本关金币 ×2 | 广告 |
| 宝箱安慰金币 | 30–80 | 35% 的关 |
| 重复卡 | 50 / 125 / 300 / 750 / 2500 | |
| 商店看广告 | 300，每天 5 次 | 广告 |
| 签到 | 7 天合计 2000 | |
| 每日挑战 | 300，七日大宝箱 1500 | 第 20 关起 |
| 任务中心 | 每日宝箱合计 200，本周宝箱合计 700 | 第 11 关起；另有收藏卡（见 5.9） |
| 抽奖奖品 | 200 / 500 / 2000 | 平均每抽回收不到两成 |

### 6.3 收支怎么对上

**一关的收入约 170**：过关 100 + 连击约 50 + 最高连击奖约 20。也就是说：

- 一条命（400）≈ 打两关多；
- 一个技能（500–1200）≈ 打 3–7 关；
- 一次抽奖（1000）≈ 打 6 关。

**一个活跃玩家的一天**（中后期，约打 15 局、过 10 关、失败 5 次）：

| | 金币 |
|---|---|
| 过关 10 次 | 1700 |
| 宝箱金币、重复卡 | 约 300 |
| 签到、每日挑战、任务中心（折到每天） | 约 900 |
| **不看广告的收入** | **约 2900** |
| 买命 1–2 条 | 400–800 |
| 技能 2–3 个（每天另有 1 个免费） | 约 2000 |
| **想花的** | **约 2600**（不含抽奖） |
| **缺口** | **没有**（删掉家园以后，见下） |

**删掉家园以后的缺口**（2026-11-17）：原来每天建一步约 2500 金币，是这张表里最大的一项支出；删掉以后不看广告的收入和想花的基本打平，「金币不够 → 看广告」的压力小了，剩下的大去处只有抽奖（1000 一次、十连 9000）。这是已知的缺口，没有真人数据前先不动数值；要补的话优先考虑：抽奖里放只有抽奖能拿到的东西、技能涨价、或者加一个新的金币去处。M3 试玩时看「每天看几次激励视频」这个数。

原来的设计是缺口靠广告补：商店看广告 5 次 1500，结算翻倍每次约 170，再加上直接换东西的广告（看广告得命、得技能、复活、开缸位）。目标是一个活跃玩家每天看 7–10 次激励视频。

**调数值时守住三条**：

1. 一关的收入不超过 200。任何新功能发的金币都要算进上面这张表。
2. 一条命至少值两关的收入，失败才有代价。
3. 要有一个净消耗大于所有一次性奖励之和（现在 2.3 万）的金币去处。原来是家园（4.9 万），2026-11-17 删掉后这一条暂时没守住，见上面「删掉家园以后的缺口」。

**失败的代价先不改，定好什么时候放宽、先放宽哪项**（2026-11-16 定）。失败扣命、一条命 400 金币、后期普通关机器人胜率 55%，叠在一起可能太重，但没有真人数据，现在改数值只是猜。M3 试玩和 M6 内测时看两件事：

- 第 26 关以后的普通关，真人首次通过率低于 50%；
- 超过三成的玩家一天里至少有一次因为没命停下不玩。

任一条出现，按下面的顺序放宽，一次只动一项，动完再看一轮数据：

1. 生命恢复从每 20 分钟一条改为每 15 分钟一条（`economy.json`）。
2. 中途点「重试」不再扣命；失败放弃复活、中途回主页照旧扣。
3. 把后段普通关的目标胜率整体上调（`docs/02` 第 2.1 节的终点 55%），不动挑战关。

不降一条命的金币价：要守住上面第 2 条。

数值全部放在配置表里，不写进代码。

| `rv_tool` | 激励视频 | 技能为 0 且金币不足 | 得 1 个该技能 |
| `rv_wheel` | 激励视频 | 抽奖页 | 抽奖 +1，每天 3 次 |
| `rv_signin_double` | 激励视频 | 签到弹窗 | 当日奖励 ×2 |
| `int_level_end` | 插屏 | 结算关闭后 | 第 8 关之后；间隔 ≥ 90 秒且至少隔 2 关；刚看完激励视频则跳过 |
| `bn_result` | Banner | 结算、暂停弹窗底部 | 局内操作区和主页不放 |

规则：

- 激励视频必须完整看完才发奖；中途关闭不发奖也不扣次数。
- 广告不可用时：有金币价的改为金币支付，其余入口隐藏，不能让玩家点了没反应。
- 所有频控数值在 `client/assets/resources/config/ads.json`。

### 7.2 开发阶段：模拟广告与广告测试页

没有真实广告接口前，用模拟实现把整条链路做完：

- **模拟广告页**（`debug` 平台）：激励视频是全屏页，显示广告位编号、5 秒倒计时，「看完」「中途关闭」「加载失败」三个按钮；插屏 1 秒后出现关闭按钮；Banner 是底部占位色块。
- **广告测试页**（设置里的入口，仅调试构建可见）：列出全部广告位，可单独触发；显示今日展示次数、频控状态，可重置频控，可切换「广告可用 / 不可用」检查降级表现。

接入真实平台时只替换 `client/assets/scripts/platform/` 里的实现，业务代码和广告位编号不变。

## 8. 新手引导

| 关 | 教什么 | 方式 |
|---|---|---|
| 1 | 点鱼进缸 | 手指指向唯一可点的目标鱼，3 种 9 条，不可能失败 |
| 2 | 暂存槽 | 故意让第一步只有非目标鱼可点 |
| 3 | 气泡遮挡 | 高亮被压住的泡 |
| 4 / 7 / 9 / 12 | 技能 | 送 2 个，强制用一次；每个技能只教一次（存档 `seenTips`），重进解锁关不再教 |
| 6 | 生命 | 第一次会扣命的关，开局提示一句，只出一次 |
| 26 | 掉落 | 开局提示一句「后面还有气泡会掉下来」，只出一次 |
| 31 | 限时缸 | 按「各机制首关」的方式教，不和掉落挤在同一关 |
| 各机制首关 | 新障碍 | 1 步手指引导 + 一句说明。哪一关弹跟着 `level_curve.json` 走（`unlock` 和第一个分层关 / 掉落关），文案键在 `economy.json` 的 `mechanicIntro`（按机制名），不另写死关号 |

引导只用手指、高亮和一句话，不用大段文字。

**功能开放引导**：过了解锁关回到主页，对应入口先放一下解锁动画（金光、图标弹起），再用脉动光圈指着它等玩家点；不弹窗、不写字。技能解锁指向商店入口。

**局内生物**：关卡里只出现 `client/assets/resources/config/species.json` 中标了 `inLevel` 的生物，且同一关内主色、轮廓都不重复。
