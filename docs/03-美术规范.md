# 03 美术规范

## 1. 原则：同品类观感，原创设计

参考截图只用来确定**品类气质**：明亮、圆润、高饱和的卡通海洋休闲风，粗描边大字，厚实的立体按钮。

除此之外全部原创，以下内容**不得**出现：

- 照着参考截图画的鱼、鱼缸、木架、头像、道具图标、场景插画、标题字。
- 参考游戏的鱼名、场景名、界面逐像素布局。
- 把参考截图作为图生图的输入喂给 Codex。

原因不只是规矩：微信、抖音、Google Play 都会因美术雷同下架并可能封号，软著和商标也过不了。

## 2. 本作的视觉识别

插画（鱼、鱼缸、气泡、图标、背景）是明亮的 Q 版卡通；**界面部件是「轻玻璃」风格**，用户 2026-11-15 从三套样稿里选定。此前的「果冻立体」方案因果冻感太重、圆角太大、高光太亮、元素没对齐被否决。

| 维度 | 设定 |
|---|---|
| 原则 | **简洁**。界面是衬托，不抢插画的戏 |
| 面板 | 半透明白色玻璃 + 细白边 + 柔和投影；浅色实底只用于弹窗、列表行、卡片 |
| 按钮 | 很淡的纵向渐变 + 细白边 + 一条细高光线 + 柔和投影；没有厚底边、没有大块高光 |
| 圆角 | 适中：按钮 30、玻璃横栏 32、弹窗 44、暂存格 18（750 宽设计稿下的像素） |
| 数字底 | 深蓝半透明胶囊，图标、数字垂直居中 |
| 对齐 | 同一条横栏里的所有元素压在同一条中线上；间距取 8 的倍数 |
| 色彩 | 蓝绿主调；绿色用于主行动按钮，紫色用于看广告，蓝色用于次要操作，橙、红作点缀 |
| 文字 | 猫啃什锦黑 Maoken Assorted Sans（OFL 许可）：粗、清楚、有游戏感但不夸张。白字加细的深蓝描边；浅色面板上用深蓝字不描边。不用造型夸张的美术字 |
| 角色 | 团子比例（头身 1:1）、大眼睛带高光点、无牙无刺 |

参考色：主蓝 `#2F8FF0`、深蓝 `#0B2E6B`、行动绿 `#4CC42E`、橙 `#FF9B21`、紫 `#8E5BD9`、红 `#F0503C`、金黄 `#FFC93C`、正文深蓝 `#27508F`。

**界面部件全部由 `tools/art/kit.py` 用代码绘制**，不用 AI 出图：AI 出的部件光泽、圆角、尺寸都不可控，也对不齐。要改风格就改这个脚本里的参数再重新生成。界面只能用 `src/ui/ui_kit.gd` 提供的部件，不直接画色块。

字体文件 14 MB，上小游戏前必须按实际用到的字做子集化。

稀有度配色：普通 冰蓝 · 精良 草绿 · 稀有 天蓝 · 史诗 紫 · 传说 金。

## 3. 资源规格

| 类别 | 尺寸（px） | 格式 | 说明 |
|---|---|---|---|
| 设计分辨率 | 750 × 1334 | — | 竖屏，按高适配，安全区内放交互 |
| 鱼 | 192 × 192 | PNG 透明 | 统一朝左，留 8px 透明边；游动用代码做挤压/摆尾，不出序列帧 |
| 图鉴大图 | 384 × 384 | PNG 透明 | 同一条鱼的大图，仅图鉴用，放分包 |
| 气泡 | 256 × 256 | PNG 透明 | 1 张底图 + 状态叠加层（锁链、冰、雾） |
| 鱼缸 | 200 × 220 | PNG 透明 | 普通 / 限时 / 大鱼缸 / 未解锁 |
| 道具与页签图标 | 144 × 144 | PNG 透明 | |
| 按钮、面板 | 九宫格 | PNG | 圆角 ≥ 24px |
| 局内背景 | 750 × 1624 | JPG 质量 80 | 覆盖长屏 |
| 家园场景 | 750 × 1000，分层 | PNG | 底图 + 10 个建造步骤的独立图层 |
| 应用图标 | 1024 × 1024 | PNG | 各平台再裁 |

- 进包前全部过 `tools/art/pack`：裁透明边、压缩（pngquant）。单张贴图 ≤ 2048 × 2048。
- 命名：`类别_名称_状态.png`，全小写下划线。例：`fish_c01_idle.png`、`btn_primary_normal.png`、`icon_tool_net.png`。

## 4. 鱼种设计规则

- 编号：`c01–c30` 普通、`u01–u15` 精良、`r01–r08` 稀有、`e01–e05` 史诗、`l01–l02` 传说。
- 每种鱼属于一个**辨识组** = 主色相（12 档）× 花纹（纯色 / 条纹 / 斑点 / 拼色）。同一关不会出现同组的两种鱼，所以画的时候只需保证跨组一眼可分。
- 色弱友好：除颜色外，每个辨识组必须有不同的轮廓特征（鳍形、体型、花纹），灰度下也能区分。
- 稀有度越高，造型越特别（发光、头饰、非鱼类如海马、水母、小章鱼），但轮廓仍要在 96px 下清晰。
- 命名原创，两到三个字，口语可爱，如「橘团子」「薄荷卷」「雪顶」。完整清单在出图前由 Claude 写入 `species.json`，用户过目后再开画。

## 5. Codex 出图流程

```
art/
  briefs/     # Claude 写的出图需求，一个资源一份 .md
  style/      # 风格锚定图：用户验收通过的样张，后续出图都以它们为参照
  raw/        # Codex 原始产出，不进包
  approved/   # 用户确认可用的图
tools/art/    # 裁边、压缩、打图集脚本
```

步骤：

1. **风格锚定**（只做一次）：Claude 按第 2 节写 brief，Codex 出 3 套风格样张（各含 3 条鱼 + 1 个鱼缸 + 1 个气泡 + 1 个按钮）。用户选定一套，存入 `art/style/`，之后所有出图都附带这套图做风格参照。
2. **批量出图**：Claude 写 brief → Codex 出图到 `art/raw/` → Claude 检查规格（尺寸、透明底、朝向、辨识度）→ 不合格附原因重出。
3. **验收**：按批次给用户看拼图总览，通过的移入 `art/approved/`。
4. **进包**：`tools/art/pack` 输出到 `assets/`。

brief 模板：

```markdown
# fish_c01 橘团子
- 用途：局内鱼 192×192 透明底，朝左
- 辨识组：橙 × 纯色
- 造型：圆团子身体，短扇形尾，头顶一撮翘起的小鳍
- 风格参照：art/style/anchor_01.png（只参照质感与比例）
- 禁止：文字、水印、背景、阴影落地、写实纹理
```

### 调用方式（2026-11-15 验证）

```bash
cd art/raw/<批次目录>
codex exec --skip-git-repo-check --sandbox workspace-write "<英文出图描述>. Use your image generation tool. Reply with only the saved file path."
```

- Codex 的图不会落在当前目录，而是存到 `~/.codex/generated_images/<会话 id>/*.png`，路径在输出的最后一行，需要自己拷回 `art/raw/`。
- 一次调用出一张图（1024×1536 左右），约 4 分钟；多张图并行跑多个进程。
- 出图描述用英文，并写明「不得出现文字、不参照任何现有游戏」。
- `art/` 目录有 `.gdignore`，Godot 不会导入里面的文件；进包的图要放 `assets/`。

### 切片

Codex 出的是白底图集，用 `tools/art/slice.py` 抠成透明底并按阅读顺序切成单张：

```bash
python3 tools/art/slice.py art/raw/batch1/fish1.png assets/fish 192 c01,c04,c05,...
```

出图描述里要写明「纯白背景、无落地阴影、元素互不接触」，否则切不开。首批资源的清单见 `art/briefs/batch1.md`。

### 界面动画约定

| 场景 | 动画 |
|---|---|
| 进关卡 | 鱼缸、暂存格、气泡、道具键依次弹出 |
| 待机 | 气泡上下漂浮、鱼摆尾、加号呼吸缩放 |
| 待机（鱼） | 除了摆尾，每条鱼还在气泡里慢慢游一小圈 |
| 点鱼 | 鱼先一缩蓄力，再沿弧线游向目标并留下一串小气泡；往右游时翻面；到达时鱼缸一扁一弹、缸口溅水花、数字跳动 |
| 破泡 | 气泡先鼓一下再炸开，薄膜向外扩散，水珠带重力四溅，闪几点星光，旁边的气泡被震得晃一下；下层气泡由暗变亮 |
| 连击 | 连续把鱼送进缸时弹出「连击 ×N」，越高字越大颜色越热；到 5 / 8 / 12 连换成夸奖语并炸一圈星星；每次连击飞一枚金币进金币栏 |
| 最后一条鱼 | 不用玩家点，气泡自己破、鱼自己入缸 |
| 过关 | 白闪 → 旋转光芒 → 大字从 3 倍砸下 → 三颗星依次亮起 → 两侧彩纸炮 → 金币喷涌飞进金币栏 → 弹出结算 |
| 满缸 | 旧缸带星星飞走，新缸弹入 |
| 障碍 | 锁和冰块脱落；点不能点的气泡会晃动 |
| 失败 | 整屏晃动；弹窗统一弹出式 |
| 界面 | 按钮按下缩小回弹，页签切换滑入，数值滚动 |

实现集中在 `src/ui/anim.gd`，新界面复用这些函数，不各写各的。

### 界面部件（assets/kit）

由 `python3 tools/art/kit.py` 生成，3 倍密度；`kit.json` 记录九宫格边距和投影留边，`Patch` 控件按设计像素绘制，任何尺寸下圆角和描边都不变形。

| 部件 | 用途 | UiKit 函数 |
|---|---|---|
| `btn_blue/green/orange/purple/red` | 按钮 | `button()` |
| `tile` | 方形道具键 | `tile_button()` |
| `glass` | 顶栏、暂存槽托盘 | `piece("glass")` |
| `chip` | 数字胶囊、进度条底 | `piece("chip")`、`capsule()` |
| `slot` | 暂存格 | `piece("slot")` |
| `fill` | 进度条填充 | `piece("fill")` |
| `panel` | 弹窗 | `PopupCard` |
| `row` / `card` / `card_gold` | 列表行、图鉴卡、签到格 | `piece()` |
| `tab_on` | 选中的页签 | `piece("tab_on")` |
| `shelf` | 鱼缸架 | `piece("shelf")` |
| `fade` | 底部渐隐衬底 | `piece("fade")` |
| `badge_green/purple`、`dot_red`、`plus`、`btn_gear`、`btn_close` | 关卡牌、角标、加号、设置与关闭 | `badge()` |

### 清晰度要求

- 抠图用 `tools/art/slice.py`：按白底混入比例还原半透明边缘并去掉白色成分，不允许用硬阈值切边。
- 所有贴图导入时生成 mipmap，画布过滤用线性 mipmap（`project.godot` 已设为默认），缩小显示才不会有锯齿。
- 贴图源尺寸至少是最大显示尺寸的 1.5 倍；背景用 1024×1536 原图。

### 风格候选

3 套风格样张在 `art/style/candidates/`（A 果冻厚涂、B 扁平贴纸、C 黏土手作），brief 见 `art/briefs/style_anchor.md`。**已选定 A**，锚定图是 `art/style/anchor_a.png`，后续出图都用 `-i` 把它作为参照图传给 Codex（提示词要写在 `-i` 之前，否则会被当成图片参数吞掉）。
