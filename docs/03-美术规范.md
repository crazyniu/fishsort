# 03 美术规范

## 1. 原则：同品类观感，原创设计

参考截图只用来确定**品类气质**：明亮、圆润、高饱和的卡通海洋休闲风，粗描边大字，厚实的立体按钮。

除此之外全部原创，以下内容**不得**出现：

- 照着参考截图画的鱼、鱼缸、木架、头像、道具图标、场景插画、标题字。
- 参考游戏的鱼名、场景名、界面逐像素布局。
- 把参考截图作为图生图的输入喂给 Codex。

原因不只是规矩：微信、抖音、Google Play 都会因美术雷同下架并可能封号，软著和商标也过不了。

## 2. 本作的视觉识别

一句话：高饱和蓝绿色海底场景，圆润大眼的彩色海洋角色，透明玻璃质感的鱼缸和气泡；界面是**轻果冻风**——实色圆角按钮靠内部下沿的深色厚度立体，顶部只有一层柔光，没有硬反光条；只有弹窗用主色厚框 + 奶油色内容区。每屏一个主按钮，其余是图标，文字少而粗、带描边。整体明亮、可爱、有玩具质感。（用户 2026-11-15 定，样稿对比后选「D 厚果冻 + 泻湖青」。）

被否决过的方向：果冻立体大高光（太重、反光太大）、轻玻璃半透明（花背景上看不清）、糖果粗描边（边框套边框）、海洋实色经典蓝（蓝色太老套）。

| 维度 | 设定 |
|---|---|
| 原则 | **简洁**。界面是衬托，不抢插画的戏 |
| 主按钮 | 每屏只有一个带字的主按钮，放在下半屏拇指区；其余操作是不带字的圆形图标键，靠红点、数字角标提示 |
| 按钮质感 | 实色，上浅下深的柔和渐变；内部下沿一圈深色厚度（约 8，750 宽设计稿像素）；顶部一层很淡的柔光；**没有硬高光条、没有白描边、没有粗描边** |
| 圆角 | 大而软：主按钮 24、图标键正圆、面板与弹窗 32、卡片 16 |
| 弹窗 | 主色厚框（框内下沿同样有深色厚度）+ 奶油色 `#FFF6E3` 内容区；最多两个按钮；关闭是右上角红色圆键 |
| 框中框 | 禁止。按钮、卡片、资源栏都不套框 |
| 形状统一 | 同类元素只用一种形状：关卡点全是圆，入口全是圆形图标，卡片全是同尺寸圆角块 |
| 文字 | 资源圆体 Resource Han Rounded CN Heavy（OFL 许可）。白字加深色描边；奶油色面板上用深色字不描边。说明文字尽量删，一个按钮最多 4 个字。**汉字和单词一律摆正：不倾斜、不旋转、不用斜体**；只有纯数字允许 ±4° 以内的轻微倾斜 |
| 色彩 | 界面主色是泻湖青；绿色用于主行动，金黄用于看广告领奖励（带紫色视频角标），橙色用于挑战关和次要花费，红色只用于关闭和红点 |
| 角色 | 团子比例（头身 1:1）、大眼睛带高光点、无牙无刺 |

参考色：主色泻湖青 `#14B8B0`（亮 `#62E3D6`、暗 `#0A8079`）、描边深青 `#07464D`、奶油 `#FFF6E3`、行动绿 `#4CC42E`、金黄 `#FFC93C`、橙 `#FF9B21`、紫 `#8E5BD9`、红 `#F0503C`、奶油面板上的正文 `#2A5157`。

**界面部件全部由 `client/tools/art/kit.mjs` 用代码绘制**，不用 AI 出图：AI 出的部件光泽、圆角、尺寸都不可控，也对不齐。要改风格就改这个脚本里的参数再重新生成。界面只能用 `client/assets/scripts/ui/kit.ts` 提供的部件，不直接画色块。

字体已裁剪到常用字（约 2.8 MB，见 `assets/fonts/LICENSE-ResourceHanRounded.txt`），上小游戏前再按实际用字裁一次。

稀有度配色：普通 冰蓝 · 精良 草绿 · 稀有 天蓝 · 史诗 紫 · 传说 金。

## 3. 资源规格

| 类别 | 尺寸（px） | 格式 | 说明 |
|---|---|---|---|
| 设计分辨率 | 750 × 1334 | — | 竖屏，按高适配，安全区内放交互 |
| 鱼 | 192 × 192 | PNG 透明 | 统一朝左，留 8px 透明边；游动用代码做挤压/摆尾，不出序列帧 |
| 收藏大图 | 384 × 384 | PNG 透明 | 同一条鱼的大图，仅收藏页用，放分包 |
| 气泡 | 256 × 256 | PNG 透明 | 1 张底图 + 状态叠加层（锁链、冰、雾） |
| 鱼缸 | 200 × 220 | PNG 透明 | 普通 / 限时 / 大鱼缸 / 未解锁 |
| 道具与页签图标 | 144 × 144 | PNG 透明 | |
| 按钮、面板 | 九宫格 | PNG | 圆角 ≥ 24px |
| 局内背景 | 750 × 1624 | JPG 质量 80 | 覆盖长屏 |
| 主页场景 | 750 × 1624 | JPG 质量 85 | 主页中间的海湾大图 |
| 订单卡 | 120 × 100 | PNG 透明 | 挂在鱼缸下的小卡片底图，生物图和进度由代码叠加 |
| 应用图标 | 1024 × 1024 | PNG | 各平台再裁 |

- **Cocos 版的进包流程**（`docs/09` 第 7、8 节）：Codex 出的插画用 `python3 client/tools/art/import_art.py --raw <art/raw 目录>` 按清单 `client/tools/art/art_manifest.json` 缩放后放进 `client/assets/resources/`（Lanczos、线性空间、透明图预乘，界面插画按最大显示尺寸 3 倍，背景存 JPG）；然后 `./run.sh art-compress` 把 PNG 量化成 256 色调色板（家园物件另缩到 2 倍），`./run.sh meta` 补 `.meta`。`ts-check` 会查没压过的图。单张贴图 ≤ 2048 × 2048。
- 界面要尽量少用位图（`docs/09` 第 11 节，用户 2026-11-16 定）：通用部件改代码绘制，位图只留鱼与少量主视觉。
- 命名：`类别_名称_状态.png`，全小写下划线。例：`fish_c01_idle.png`、`btn_primary_normal.png`、`icon_tool_net.png`。

## 4. 生物设计规则

局内出场的生物和收藏卡分开管理。

### 4.1 局内生物（16 种，辨识第一）

- **不限于鱼**：小丑鱼、河豚、海星、鲨鱼、螃蟹、章鱼、海马、水母、海龟、鳐鱼、贝壳、乌贼、龙虾、灯笼鱼、剑鱼、海豚等，轮廓各不相同。
- **硬规则：同一关里任意两种必须「主色相」和「轮廓」都不同。** 只靠颜色、或只靠花纹区分的不合格。每种登记一个主色相（12 档）和一个轮廓类（圆 / 扁长 / 竖长 / 星形 / 横宽带钳 / 伞形 / 菱形 / 多足 / 带壳 / 尖吻），`species.json` 里记录，运行时挑选本关生物时按这两项去重。
- 验收方法：缩到 64px、再转灰度，16 种两两仍能一眼分清；拍一张 16 种并排的对照图给用户确认。
- 局内只从「已有美术」的生物里挑，按主色相和轮廓去重（`client/assets/scripts/core/model/speciesPick.ts`）；第一版的 12 条普通鱼里颜色或体型相近的，换成新画的 16 种。
- 统一团子比例、大眼睛高光、无牙无刺，鲨鱼也要可爱。

### 4.2 收藏卡（60 张）

- 编号：`c01–c30` 普通、`u01–u15` 精良、`r01–r08` 稀有、`e01–e05` 史诗、`l01–l02` 传说。局内 16 种同时是收藏里的普通卡。
- 稀有度越高造型越特别（发光、头饰、稀奇物种），不要求同屏可分。
- 命名原创，两到三个字，口语可爱，如「橘团子」「薄荷卷」「雪顶」。清单由 Claude 写入 `species.json`，用户过目后再开画。

## 5. Codex 出图流程

```
art/
  briefs/     # Claude 写的出图需求，一个资源一份 .md
  style/      # 风格锚定图：用户验收通过的样张，后续出图都以它们为参照
  raw/        # Codex 原始产出，不进包
  approved/   # 用户确认可用的图
tools/art/    # 裁边、压缩、打图集脚本
```

步骤：

1. **风格锚定**（只做一次）：Claude 按第 2 节写 brief，Codex 出 3 套风格样张（各含 3 条鱼 + 1 个鱼缸 + 1 个气泡 + 1 个按钮）。用户选定一套，存入 `art/style/`，之后所有出图都附带这套图做风格参照。
2. **批量出图**：Claude 写 brief → Codex 出图到 `art/raw/` → Claude 检查规格（尺寸、透明底、朝向、辨识度）→ 不合格附原因重出。
3. **验收**：按批次给用户看拼图总览，通过的移入 `art/approved/`。
4. **进包**：`tools/art/pack.py` 处理后放进 `assets/`。

brief 模板：

```markdown
# fish_c01 橘团子
- 用途：局内鱼 192×192 透明底，朝左
- 辨识组：橙 × 纯色
- 造型：圆团子身体，短扇形尾，头顶一撮翘起的小鳍
- 风格参照：art/style/anchor_01.png（只参照质感与比例）
- 禁止：文字、水印、背景、阴影落地、写实纹理
```

### 调用方式（2026-11-15 验证）

```bash
cd art/raw/<批次目录>
codex exec --skip-git-repo-check --sandbox workspace-write "<英文出图描述>. Use your image generation tool. Reply with only the saved file path."
```

- Codex 的图不会落在当前目录，而是存到 `~/.codex/generated_images/<会话 id>/*.png`，路径在输出的最后一行，需要自己拷回 `art/raw/`。
- 一次调用出一张图（1024×1536 左右），约 4 分钟；多张图并行跑多个进程。
- 出图描述用英文，并写明「不得出现文字、不参照任何现有游戏」。
- `art/` 不进包；进包的图要经上面的流程放进 `client/assets/resources/`。

### 切片

Codex 出的是白底图集，用 `tools/art/slice.py` 抠成透明底并按阅读顺序切成单张：

```bash
python3 tools/art/slice.py art/raw/batch1/fish1.png assets/fish 192 c01,c04,c05,...
```

出图描述里要写明「纯白背景、无落地阴影、元素互不接触」，否则切不开。首批资源的清单见 `art/briefs/batch1.md`。

### 界面动画约定

| 场景 | 动画 |
|---|---|
| 进关卡 | 鱼缸、暂存格、气泡、道具键依次弹出 |
| 待机 | 气泡上下漂浮、鱼摆尾、加号呼吸缩放 |
| 待机（鱼） | 除了摆尾，每条鱼还在气泡里慢慢游一小圈 |
| 点鱼、入缸、满缸、连击、结算 | 以 `docs/01` 第 3 节为准，那里是验收标准 |
| 新气泡落下 | 从屏幕上方落入、落地轻弹、挤开周围气泡 |
| 障碍 | 锁和冰块脱落；点不能点的气泡会晃动 |
| 失败 | 整屏晃动；弹窗统一弹出式 |
| 界面 | 按钮按下缩小回弹，页签切换滑入，数值滚动 |

实现集中在 `client/assets/scripts/ui/fx.ts`，新界面复用这些函数，不各写各的。

### 界面部件（`client/assets/resources/ui/kit`）

由 `client/tools/art/kit.mjs` 用 SVG 写出、resvg 按 3 倍渲染成透明 PNG 并直接量化（`node tools/art/kit.mjs [--sheet 总览.png]`）；九宫格边距记在 `client/tools/art/slices.json`，`.meta` 生成时写进去，代码里用 `ui/kit.ts` 的 `slice()` 拉伸（皮放在缩小 1/3 的子节点上，任何尺寸下圆角和描边都不变形）。部件有：各色胶囊按钮与圆按钮、弹窗框（`panel`、`panel_blue`、标题凸台 `popup_head`）、玻璃卡片 `panel_glass`、列表行 `row` / `row_blue`、标题底板、信息胶囊、进度条、暂存格、木架、鱼缸、气泡、选关节点与路线、收藏册封面、收藏卡框、线条图标、手指、特效（光、星、环、射线、彩纸）。

按 `docs/09` 第 11 节，这些部件之后改成运行时代码绘制，不再进包。

### 弹窗

所有弹窗（暂停、设置、生命、开缸位、复活、离开确认、功能解锁）共用一套：

- 一层实色深海蓝面板，圆角 18，不透明；**里面不再套浅色内框**。
- 标题压在面板顶部一条亮蓝色带上，白字摆正。
- 右上角红色圆形关闭键，略微探出面板。
- 图标直接放在面板上，说明文字用白字，数值用金黄。
- 按钮最多两个：主按钮绿色在右，次按钮蓝或橙在左；看广告的按钮右上角带小视频角标，金币价按钮左侧带金币图标。
- 出现时缩放回弹约 0.2 秒，背景压暗 60%；点背景不关闭带代价的弹窗。

### 清晰度要求

- 抠图用 `tools/art/slice.py`：按白底混入比例还原半透明边缘并去掉白色成分，不允许用硬阈值切边。
- 所有贴图的 `.meta` 都开 mipmap、线性过滤（`./run.sh meta` 生成），缩小显示才不会有锯齿。
- 贴图源尺寸至少是最大显示尺寸的 1.5 倍；背景用 1024×1536 原图。

### 风格候选

3 套风格样张在 `art/style/candidates/`（A 果冻厚涂、B 扁平贴纸、C 黏土手作），brief 见 `art/briefs/style_anchor.md`。**已选定 A**，锚定图是 `art/style/anchor_a.png`，后续出图都用 `-i` 把它作为参照图传给 Codex（提示词要写在 `-i` 之前，否则会被当成图片参数吞掉）。
