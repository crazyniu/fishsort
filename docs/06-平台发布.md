## 2. 微信小游戏

- 包体：主包 ≤ 4 MB。安装包里只放引擎、脚本和加载页，其余资源放云开发的静态网站托管、加载页里下载（`docs/04` 第 8 节，`docs/10` 第 4 节）。托管的域名要加进「downloadFile 合法域名」。
- 类目：休闲游戏。提交软著、自审自查报告。
- **提交审核时网络类型选「联网」**：资源要从网上下载，选错了微信按离线模式审，`wx.downloadFile` 直接报 `api can't use in offline mode`，停在加载页、被驳回「打不开」（2026-11-21 踩过）。
- 变现：流量主（激励视频、插屏）。个人主体的小游戏累计独立访客满约 500 人才能开通（2026-11-18 查到的说法，以后台为准），上线初期没有广告：看广告的按钮隐藏，有金币价的改用金币，不另做备用方案，靠前期关卡简单撑过（`docs/01` 7.1）。
- 不接虚拟支付（需要版号）。
- 必做：用户隐私保护指引、隐私授权弹窗；好友榜走开放数据域，主域拿不到好友数据。
- 分享：不得诱导分享（「分享才能继续」「分享得奖励」都不行）。本作分享不给任何奖励，只有普通转发（`docs/01` 5.8）。
- 内容：不出现赌博式抽奖表述；收藏开卡的概率要在界面里公示。

## 3. iOS（只上海外）

- 产物：Cocos 出 Xcode 工程，在用户的 Mac 上打包签名、传 App Store Connect。上架区域不选中国大陆（大陆上架游戏要版号）。
- 设备：只做 iPhone 版（`TARGETED_DEVICE_FAMILY = 1`），在 iPad 上按 iPhone 比例运行，不交 iPad 截图。
- 语言：英文、简体中文、繁体中文、日文、韩文、德文、法文、西班牙文、葡萄牙文（巴西）、意大利文、俄文、土耳其文（`docs/10` 第 8 节）；App Store Connect 里每种语言填一份商店文案（`store/listing.md`）。上架区域不选中国大陆。
- 广告：AdMob；启动时先弹 UMP 同意表（只有需要的地区），再弹 ATT 跟踪授权（不同意也能玩，只是广告不个性化）。App Store Connect 的 App 隐私按 AdMob 填：收集「标识符（设备 ID）」「使用数据（广告数据）」「诊断」，用于第三方广告，「是否用于跟踪」选是（Google 的说明：https://developers.google.com/admob/ios/privacy/data-disclosure ）。
- 内购：这一版不做。以后做时用 StoreKit，去广告为非消耗型、金币包为消耗型，必须有「恢复购买」；数字商品只能走苹果内购。
- 抽奖与宝箱：各奖品和各稀有度的概率在抽奖页、收藏页公示（这一版金币不卖，但公示一直保留，以后开内购也不用补）。
- 排行榜与云存档：Game Center、iCloud。
- 分级：App Store 年龄分级问卷，按 12+ 左右填（有随机奖励；以后开了广告也是这一档）。

## 4. Google Play

- 产物：AAB（Google Play 不收 APK；APK 只给自己装手机测试），仅 arm64-v8a + armeabi-v7a，用上传密钥签名、真实广告位（`./package.sh` → 3 Android → 2 AAB）。`targetSdk` 36（`game.json` 的 `android.targetSdk`；Google Play 2026-08-31 起新应用和更新都要 Android 16 / API 36，每年 8 月底跟着提一级，提交前核对）；清单里 `android:appCategory="game"`（API 36 起大屏会忽略「只能竖屏」，游戏不受约束）。需支持 16 KB 内存页：`./package.sh` 打完 AAB 自动用 NDK 的 `llvm-readelf` 查 arm64 原生库是否按 16 KB 对齐。
- 语言：英文、简体中文、繁体中文、日文、韩文、德文、法文、西班牙文、葡萄牙文（巴西）、意大利文、俄文、土耳其文（用户 2026-11-19 加日韩、欧洲语言和繁体）。上架地区为海外，含台湾、香港。
- 受众：目标年龄设为 13 岁以上，避开家庭政策对广告 SDK 的额外限制；商店素材不要做得明显面向幼儿。
- 广告：AdMob，接 UMP 同意弹窗（欧洲经济区等地区必需），清单里声明广告 ID 权限；**去掉应用内购买权限**（`com.android.vending.BILLING`，是依赖库合并进来的，`AndroidManifest.xml` 里用 `tools:node="remove"` 删掉，2026-11-20；这一版不做内购，带着它 Play 会标「含应用内购买」）。Wi-Fi 和竖屏两项硬件在清单里标成非必需（`uses-feature … required="false"`，2026-11-21 从 #157 移过来）：不标的话 Play 会按 Wi-Fi 权限和竖屏方向推断设备必须有，没有的平板、Chromebook 装不了。Play 后台「广告」声明选「含广告」，「广告 ID」选用于广告；数据安全表单按 AdMob 填：收集设备或其他 ID、应用互动、诊断数据，用于广告，和第三方共享（Google 的说明：https://developers.google.com/admob/android/privacy/play-data-disclosure ）。
- 内购：这一版不做。以后做时用 Play Billing，去广告为非消耗型、金币包为消耗型，提供「恢复购买」。
- 必填：数据安全表单、内容分级问卷、广告声明、隐私政策链接（第一版不收集数据也要有隐私政策链接）。
- 抽奖与宝箱：各奖品和各稀有度的概率在抽奖页、收藏页公示（以后开内购、金币能用钱买时，这是苹果和台湾法规都要求的）。
- 排行榜与云存档：Play Games Services v2。

## 6. 提审前检查

- [ ] 第 1 节资质齐全
- [ ] 隐私政策与实际采集一致，弹窗在采集前出现
- [ ] 无广告填充时全流程可玩（看广告的入口变灰，不卡流程）
- [ ] 上架包是用 `./package.sh` 的 iOS IPA / Android AAB 打的（只有这两种用真实广告位，其它产物用 Google 的测试广告位）；装上以后看到的广告不带「Test Ad」字样
- [ ] 测试时不要点自己的真实广告（会被 AdMob 判成无效流量，严重的封号）；要在真机上试真实广告，先在 AdMob 后台「设置 → 测试设备」加上自己的手机
- [ ] 商店后台的广告、跟踪、数据收集声明和包里实际一致（含广告、iOS 有跟踪授权）
- [ ] 两个商店的开发者网站填的是 `https://www.shopkivoo.com`；AdMob 后台的 app-ads.txt 显示「已验证」（上架并关联商店后 AdMob 才去抓，要等一两天）
- [ ] 断网可玩（小游戏首次加载除外）
- [ ] 包体在预算内
- [ ] 正式版里没有「难度调试」：它只在 `./run.sh` 打的调试构建里出现（`PlatformBase.isDevBuild`），`./package.sh` 打的包一律不出，微信体验版也不出，不用改开关（`docs/10` 第 9 节）。上架前在正式版里看一眼设置。各档关卡 `config/levels_lab/`（约 20 MB）`./package.sh` 构建时自动挪出、不进包，构建完挪回来，不用手动删
- [ ] 美术、名称、图标无雷同（对照 `docs/03` 第 1 节）
- [ ] 概率公示页存在
- [ ] 中英文案无缺失
- [ ] iOS 拒绝 ATT 后能正常玩（开了广告以后）
- [ ] 低端机性能达标
