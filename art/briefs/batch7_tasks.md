# 第 7 批：任务中心的图标

风格沿用 `art/style/anchor_a.png` 与 `style_anchor.md`（果冻厚涂、深色描边、顶部高光）。全部原创，不参考任何现有游戏的截图，图里不出现文字。玩法与界面见 `docs/01` 第 5.9 节、`docs/ux/tasks.md`。

| 进包文件（`client/assets/resources/ui/icon/`） | 尺寸 | 内容 |
|---|---|---|
| `tab_tasks.png` | 和另外四个页签图标同尺寸、透明底 | 「任务」页签：一块贝壳边的小任务板，上面三行小横条，其中两行前面打了绿色对勾，板子右上角别着一颗金色海星。和商店、家园、主页、收藏四个页签图标是一套：同样的角度、光源、描边粗细 |
| `task_win.png` | 144×144 透明 | 「过关」：一面插在沙堆上的小三角旗，旗面上一颗星 |
| `task_combo.png` | 144×144 透明 | 「连击」：三个一串往右上冒的气泡，一个比一个大，带速度线和小火花 |
| `task_ad.png` | 144×144 透明 | 「看广告」：一块圆角小屏幕，中间一个播放三角 |
| `task_share.png` | 144×144 透明 | 「分享」：一只漂流瓶，瓶口飘出一颗小爱心 |

出图要求：纯白背景、无落地阴影、元素互不接触，一张图放两到三个图标，之后用 `tools/art/slice.py` 切开。

出图前代码里借用现有图标：页签沿用原排行页签的奖杯图（文件已改名 `tab_tasks.png`），过关用主页页签图标，连击用星星，看广告、分享用按钮上的小白图标。其余任务（救鱼、技能、每日挑战、抽奖、家园）和宝箱一直用现有的图，不用新出。
