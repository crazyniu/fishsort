# 风格锚定样张（M2 第一步）

目的：出 3 套风格样张，用户选定一套作为后续所有出图的风格参照。

每张样张内容相同，只有画法不同。一张图，浅色纯色背景，元素分开摆放互不重叠，**画面中不得有任何文字、字母、数字、水印**：

1. 三条原创小鱼，朝左，团子比例（头身 1:1）、大眼睛带一个高光点、无牙无刺：
   - 橘色纯色，短扇形尾，头顶一撮翘起的小鳍
   - 薄荷绿带白色竖条纹，身体略扁，长飘带尾
   - 莓紫色带浅色圆斑，球形身体，小圆鳍
2. 一个鱼缸：圆角方形的果冻质感水箱，顶上一个贝壳盖，放在珊瑚枝搭成的架子上
3. 一个气泡：带彩虹薄膜反光的肥皂泡，里面是空的
4. 一个空白主按钮：珊瑚橙色圆角厚按钮，有立体厚度，上面没有字

通用设定：明亮、圆润、高饱和的卡通浅海休闲手游风；主色珊瑚橙 #FF7A59 与薄荷青 #2EC4B6，辅色奶油白 #FFF6E5、柠檬黄 #FFD23F、莓紫 #8E5BD9；描边用深青 #0E4A5A 而不是纯黑。全部为原创设计，不参照任何现有游戏的角色或界面。

| 样张 | 画法 |
|---|---|
| A 果冻厚涂 | 2.5D 厚涂，果冻般的通透光泽，柔和渐变，顶光加底部环境反光，细的深青描边 |
| B 扁平贴纸 | 扁平矢量贴纸风，粗的奶油白外描边加一圈偏移投影，只有两三级色阶，几乎不做渐变 |
| C 黏土手作 | 软陶/橡皮泥质感的 3D 渲染观感，哑光表面，柔和的摄影棚布光，无描边 |

输出：`art/raw/style/style_a.png`、`style_b.png`、`style_c.png`，竖版，约 1024×1536。
