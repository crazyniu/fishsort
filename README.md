# 啵啵救援队（fishsort）

竖屏休闲消除游戏：点开气泡里的小鱼，按种类送回鱼缸，三条一缸。

- 平台：微信小游戏（中国大陆）· Google Play · App Store（海外），一个仓库一个主干（[开发底座](docs/10-开发底座.md)）
- 打包：运行 `./package.sh`，输入编号选择微信小游戏、iOS、Android 或网页版。iOS 和 Android 再选产物，详见[打包说明](docs/10-开发底座.md#4-打包)。
- 引擎：Cocos Creator 3.8.8 + TypeScript，工程在 [`client/`](client/)
- 试玩：在装了 Cocos Creator 的 Mac 上跑 `./run.sh`（`./run.sh help` 看全部命令）

从 [`CLAUDE.md`](CLAUDE.md) 开始读，设计与规范在 [`docs/`](docs/)。
